# ЮЛДУЗ — Свет Самарканда

Аниме-короткометражка (пилот, 3:20, 1920×1080, 16:9, 24 к/с) в японской рисовке и узбекском мире:
Самарканд, Регистан, обсерватория Улугбека, Сиабский базар, хан-атлас, икат, доппи, чапан, птица Хумо, демон Дев.
Озвучка на русском, синтезированная музыка в узбекском ладу (дутар, дойра, карнай, най), шумы и эффекты.

Готовое видео: `out/yulduz-1920x1080.mp4` (собирается `./build.sh`).
Сюжет, герои и мир подробно — в [STORY.md](STORY.md).

## Как устроено

| Файл | Что делает |
|---|---|
| `script.json` | Реплики, голоса персонажей (RHVoice), высота и темп голоса, субтитры |
| `tts.py` | Синтез речи → обработка (эхо для Хумо, демонический голос Дева, «мысли» Жасура) → `out/voices/*.wav` и `voice_data.js` (длительности + огибающие для губ) |
| `lib.js` | Изинги, детерминированный рандом, SVG-хелперы, эффекты: линии скорости, частицы (листья чинары, искры, звёзды), лучи, магический круг-гирих, трещины, ударные кольца |
| `chars.js` | Персонажи: аниме-лицо (глаза с бликами, моргание, брови, рот по голосу), причёски, одежда (хан-атлас, икат, чапан, доппи), фигуры в полный рост на скелете, птица Хумо, Дев |
| `scenes.js` | Фоны: Регистан, купола, минареты, махалля, школа №17, класс, двор с арыком, обсерватория Улугбека, Сиабский базар |
| `shots.js` | Раскадровка: 50 планов, камера, тряска, импакт-кадры, тайминги реплик, звуковые события |
| `audio.py` | Саундтрек по частям (пролог, утро, хулиганы, ночь, превращение, кризис, бой 150 BPM, рассвет, эпилог), шумы, дакинг музыки под голос → `out/mix.wav` |
| `render.mjs` | Покадровый рендер через Chromium (Playwright) параллельно в несколько страниц, сборка ffmpeg |

## Сборка

Нужны Node.js с Playwright (Chromium), Python 3 с numpy, ffmpeg. Для пересинтеза голосов — RHVoice
(`tools/build_rhvoice.sh` собирает его из исходников с русскими голосами).

```bash
./build.sh                      # тайминги → музыка → кадры → out/yulduz-1920x1080.mp4
./build.sh --tts                # то же, но с пересинтезом голосов
node render.mjs --stills 42,103 # стоп-кадры в out/stills/
python3 tools/contact.py        # контрольные листы всех планов в out/contact/
```

Предпросмотр: открыть `index.html` (проигрывается по кругу) или `index.html?t=103.5` (стоп-кадр).
