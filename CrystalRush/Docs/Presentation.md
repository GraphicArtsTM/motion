## Слайд 7 — код (GameManager, 13 строк)

```csharp
public void LoseLife()
{
    if (State != GameState.Playing) return;   // во время паузы и Game Over урон не наносится

    Lives = Mathf.Max(0, Lives - 1);
    StatsChanged?.Invoke();                   // GameUI обновит HUD

    if (Lives == 0) EndRound(LoseReason.NoLives);
}

void SetState(GameState newState)
{
    State = newState;
    Time.timeScale = newState == GameState.Playing ? 1f : 0f; // пауза физики и таймера
    StateChanged?.Invoke(newState);           // GameUI покажет нужную панель
}
```

Объяснение: GameManager хранит состояние раунда и только сообщает о нём событиями.
Интерфейс подписан на события и сам ничего не меняет — одна задача на скрипт.

## Слайд 10 — реальные проблемы (примеры, замените своими)

1. **Пробел ставил игру на паузу.** После клика по кнопке «II» она оставалась выделенной в EventSystem,
   и Пробел (рывок) «нажимал» её снова. Решение: пока идёт игра, `GameUI` снимает выделение с UI-кнопок.
2. **Шар «застревал» на стыках плиток пола.** У каждой плитки был свой коллайдер, шар цеплялся за рёбра.
   Решение: плитки только для красоты, у пола один большой BoxCollider.
3. **Шипы не били стоящего игрока.** Rigidbody «засыпал», и триггер не срабатывал. Решение: `sleepThreshold = 0`.
