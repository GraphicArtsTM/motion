# Royal Run — мультиплеер (Unity 6000.3.26f1)

Готовый Unity-проект по руководству «Royal Run: Building from Scratch + Multiplayer»:
бесконечный раннер на 1–3 игрока, телефоны работают как джойстики по Wi-Fi.
Языки игры и страницы на телефоне: **русский, английский, узбекский**.

## Как открыть

1. Распакуйте папку `RoyalRun` в путь **без кириллицы и пробелов**, например `C:\Unity\RoyalRun`.
2. Unity Hub → **Projects** → **Add** → **Add project from disk** → выберите папку `RoyalRun`
   (ту, в которой лежат `Assets`, `Packages`, `ProjectSettings`).
3. Откройте проект в редакторе **6000.3.26f1**. Первый запуск занимает 1–5 минут: Unity скачивает пакеты.
4. Если Unity спросит про **Input System** («enable the new input backends? … restart») — нажмите **Yes**.
   Игра работает и с новой, и со старой системой ввода, так что подойдёт любой ответ.
5. Сцена `Assets/Scenes/Game` откроется сама (или меню **Royal Run → Open Game Scene**).
6. Нажмите **Play**. В окне Game включите **Maximize On Play** (и Scale = 1x).

Готовые модели, музыка и префабы из руководства (GDTV Assets, King, Blackmoor Tides) в проект **не нужны**:
герои, дорога, заборы, монеты, яблоки, падающие препятствия, звуки и музыка создаются кодом при запуске.

## Режимы и управление (жанр «бесконечный раннер»)

**Бесконечный** (по умолчанию): бег по трём полосам, дорога постепенно ускоряется. Каждые 6–9 участков
дорога **поворачивает на 90°** — нужно успеть сделать свайп (или нажать ←/→) в сторону поворота, пока
герой на перекрёстке (подсказка — мигающие стрелки ◄◄◄ / ►►►). Не успел — врезался в тупиковую стену.
* **Низкий забор, повозка, падающий предмет** — герой спотыкается, сзади появляется **каменный голем**.
  Споткнёшься ещё раз, пока он рядом (7 с), — он ловит героя.
* **Высокая стена** и **балка на уровне головы** — забег окончен. Стену обходят, под балкой проезжают **подкатом**.
* Щит спасает от любого удара. Монеты, комбо, магнит, самоцветы — как раньше.

**На время** (классика из руководства): таймер, чекпоинты добавляют время, удары отнимают время.
Режим переключается кнопкой «РЕЖИМ» на экране выбора героя (в лобби мультиплеера — клавиша M).

| Действие | Телефон (Android) | Клавиатура | Пульт-телефон (мультиплеер) |
|---|---|---|---|
| Полоса / поворот | свайп ← → | ← → или A D | свайп ← → |
| Прыжок | свайп ↑ | ↑, W, Пробел | свайп ↑ или касание |
| Подкат (в воздухе — быстро вниз) | свайп ↓ | ↓, S | свайп ↓ |
| Пауза | кнопка «II» | Esc | — |

## Android

1. Unity Hub → Installs → ваша версия → Add modules → **Android Build Support** (с SDK & NDK и OpenJDK).
2. В редакторе: меню **Royal Run → Setup Android Build** (вертикальный экран, IL2CPP, ARM64,
   пакет `com.royalrun.game`, переключение платформы).
3. **Royal Run → Build Android APK** — получится `Builds/RoyalRun.apk`, его можно поставить на телефон.

На телефоне игра сама включает облегчённый режим: вертикальный экран, экран не гаснет, меньше деревьев
и участков дороги впереди, текстуры меньше и без карт нормалей, жёсткие тени на короткой дистанции,
меньше эффектов, без сервера для других телефонов (мультиплеер — с компьютера). Интерфейс учитывает
вырез камеры (safe area); кнопка «Назад» = пауза / выход в меню.

Оптимизация для телефона:
* все одноцветные детали участка дороги перепаковываются в 3 общих «палитровых» материала —
  кусок дороги рисуется за несколько draw calls вместо десятков;
* герой и голем — одна skinned-сетка с одним материалом-палитрой (1–3 draw calls на персонажа);
* рендер не больше 1600 px по длинной стороне (на экранах 2400×1080 видеочип рисует вдвое меньше пикселей);
* земля и дорога не участвуют в проходе теней; рельеф на телефоне с меньшим числом треугольников;
* горы на горизонте — плоские силуэты без освещения и тумана (почти бесплатно).

## Язык

В главном меню кнопка **ЯЗЫК / LANGUAGE / TIL** переключает русский → английский → узбекский.
Выбор запоминается. Страница на телефонах переключается вместе с игрой.

## Управление

| Где | Клавиши |
|---|---|
| Меню | ↑/↓ или W/S — выбор, Enter — подтвердить, мышь тоже работает, F1 — помощь с телефоном |
| Выбор героя | ←/→ — герой, Enter — играть, Esc — назад |
| Игра | WASD или стрелки — бег, **Пробел — прыжок**, Esc — пауза |
| Лобби | Tab — следующий адрес, K — игрок с клавиатуры (до 3 на одной клавиатуре), ←/→ — выбор героя, Enter — готов, L — убрать |
| Результаты | Enter — заново, L — добавить игроков / сменить героя, Esc — меню |

## Геймплей

* **Прыжок** (Пробел или короткое касание экрана телефона) — низкие красно-белые заборы можно перепрыгнуть.
  **Высокие каменные стены** перепрыгнуть нельзя — только обойти.
* **Комбо:** каждые 10 монет подряд без удара повышают множитель (x2 … x5). Удар сбрасывает комбо.
* **Очки** = монеты × множитель + 1 очко за каждый пробежанный метр.
* **Бонусы на дороге:** 🛡 щит (поглощает один удар, 10 с), 🧲 магнит (монеты летят к герою, 8 с),
  ⏳ песочные часы (+4 с). Редкий **самоцвет** в конце цепочки монет — 500 очков.
* **Дуги монет над заборами** — средние монеты достаются только в прыжке.
* **Повозки**, которые ездят поперёк дороги (их можно перепрыгнуть).
* **Три зоны:** зелёные луга → осенний лес → зимние горы. Каждый чекпоинт ведёт в следующую зону,
  а дорога после него становится чуть быстрее.
* Яблоко ускоряет, удар замедляет, чекпоинт добавляет время — как в руководстве.
* В результатах: дистанция, собранные монеты и лучший множитель комбо.

## Удар

Врезаться в забор, стену, повозку или падающий предмет — заметное событие:
препятствие разлетается на обломки, героя отбрасывает назад с подскоком, управление на миг пропадает,
дорога почти останавливается и снова разгоняется, **со времени снимается 2 с** (стена — 3 с), комбо сбрасывается,
экран вспыхивает красным и трясётся, телефон вибрирует. Затем 1,2 с герой мигает и не получает новых ударов.
Щит принимает удар на себя (препятствие всё равно разбивается).

## Графика

* Деревни с домиками (фахверк или камень, окна светятся, ящики с цветами), мельницы с вращающимися крыльями,
  дамбы через озёра (вода, кувшинки, камыш, каменная балюстрада), облака над дорогой.
* У каждого героя своя манера бега; плюмаж, капюшон и шарф покачиваются; из-под ног летит пыль.
* Процедурные текстуры с картами нормалей (без файлов картинок): брусчатка, трава, доски, кора, кирпич,
  камень, листва, металл, ткань. Матовые материалы вместо «пластика»; металл слегка отражает небо.
* Дневное небо с солнцем, мягкие тени, дымка у горизонта под цвет неба.
* Дорога идёт по гребню: у обочины луга и пригорки с цветами и травой, дальше склоны с лесом уходят в
  долину на 22 м вниз, на горизонте два хребта гор со снежными вершинами (нет больше «пустой коробки»).
  Под дамбами — пруд в низине. Дома, мельницы и замки стоят на склонах с фундаментом.

## Звук

Все звуки и музыка синтезируются кодом при запуске (`SynthAudio.cs`, файлов нет): FM-колокольчики,
фильтрованный шум, «медные» аккорды, щипковые струны (Karplus-Strong), барабаны и реверберация.

* **Музыка:** в меню — спокойная мелодия на лютне с флейтой (ре дорийский, 92 BPM), в забеге — героическая
  тема (ля минор, 128 BPM: бочка, тайко, бас, арпеджио, медь). Треки плавно сменяются, на паузе и в
  результатах музыка тише. Музыка готовится в фоновом потоке, поэтому запуск не тормозит.
* **Бег:** шаги (4 варианта), прыжок, приземление, подкат, свист при смене полосы (слева/справа в
  стереопанораме), поворот, ветер, который усиливается со скоростью, и птицы (кроме снежной зоны).
* **Бонусы:** монеты (каждая следующая в серии звучит выше), кристаллы, яблоко (хруст), щит, разбитый щит,
  магнит, песочные часы, комбо, ускорение, фанфары чекпоинта.
* **Удары:** спотыкание, разбитое препятствие, крушение; голем рычит и тяжело топает (громче, когда ближе).
* **Интерфейс:** отсчёт, «Старт!», щелчки при выборе, подтверждение и «назад»; в конце забега грустная
  мелодия, при победе и в конце классического забега — фанфары, при новом рекорде — отдельная мелодия.
* Кнопка **«Звук: вкл/выкл»** в главном меню (запоминается).
* Свою музыку можно положить в поле `Music` у `GameAssets` — она заменит синтезированную тему забега.

## Камера

* Перед стартом камера облетает героя (от лица к спине), затем «ВПЕРЁД!».
* Камера ближе к герою и **не отдаляется при ускорении** (угол обзора меняется лишь на несколько градусов).
* Плавно следует за героем, наклоняется в поворотах, смотрит вперёд на скорости, поднимается за прыжком,
  слегка «проседает» при приземлении и дёргается вперёд при ударе.
* Тряска плавная (шум Перлина): маленькие толчки еле заметны, сильные — ощутимы.
* Когда время вышло, камера медленно облетает уставшего героя.
* В меню и лобби камера едва заметно «дышит» — зал за героями слегка смещается.
* В одиночной игре сохраняется рекорд.

### Несколько игроков на одной клавиатуре

В лобби мультиплеера нажмите **K** до трёх раз. Раскладки:
игрок 1 — WASD + Пробел, игрок 2 — стрелки + правый Shift, игрок 3 — NumPad 8/4/5/6 + NumPad 0.
Можно смешивать: например, двое за клавиатурой и один с телефона.

## Гонка по Wi-Fi (телефоны и компьютеры)

Каждый игрок бежит **на своём устройстве** (Android-телефон или компьютер), все — по **одной и той же
дороге** (у всех одинаковое «зерно» генерации: те же повороты, заборы, монеты). Соперники видны на дороге
«призраками» с именем и отставанием («+12 m»), справа сверху — живая таблица мест.

1. Все устройства — в одной сети Wi-Fi.
2. Один игрок: **ГОНКА ПО WI-FI → СОЗДАТЬ ИГРУ**. Он ведущий: выбирает режим и нажимает **СТАРТ**.
3. Остальные: **ГОНКА ПО WI-FI** — комната находится сама (поиск по сети ~3 с) → **ВОЙТИ**.
   Кнопкой «ГЕРОЙ» можно сменить героя прямо в комнате.
4. После финиша видны места всех игроков (обновляются, пока остальные бегут).
   Ведущий нажимает **ЕЩЁ РАЗ** — все возвращаются в комнату.

До 4 игроков. Порт 8095 (TCP). На Windows при создании игры разрешите доступ в частных сетях.
Если игра не находится — проверьте, что «гостевая» сеть роутера не запрещает устройствам видеть друг друга.

## Один экран: телефоны как пульты (только компьютер)

1. Меню → **МУЛЬТИПЛЕЕР**. На экране появятся адрес вида `http://192.168.1.5:8080` и QR-код.
2. Телефон в **той же Wi-Fi сети**, что и компьютер → наведите камеру на QR-код.
3. Введите имя, выберите героя, нажмите **ГОТОВ**. Когда готовы все — отсчёт 3-2-1 и экран делится на 2–3 части.

Windows при первом запуске спросит про доступ к сети — разрешите **частные сети**.
Если окно закрыто, выполните в командной строке от имени администратора:

```
netsh advfirewall firewall add rule name="Royal Run" dir=in action=allow protocol=TCP localport=8080-8090
```

Подробная диагностика — клавиша **F1** в игре.

## Герои

Герои — гладкие модели (не кубики): тело, руки и ноги — сглаженные формы (эллипсоиды, тела вращения,
скруглённые коробки), всё собрано в одну skinned-сетку со скелетом, локти и колени сгибаются плавно.
У каждого лицо с глазами, бровями и ртом, причёска и свой костюм (корона и мантия с горностаем, шлем с
плюмажем и щит, капюшон и лук, шляпа звездочёта и зелье, очки-гогглы и огненные кулаки).


| Герой | Бонус |
|---|---|
| Король / King / Qirol | без бонусов и без слабостей |
| Рыцарь / Knight / Ritsar | смена полосы быстрее на 30% |
| Следопыт / Ranger / Izquvar | монеты дают на 50% больше очков |
| Алхимик / Alchemist / Kimyogar | +5 с на старте и +3 с на каждом чекпоинте |
| Пиро / Pyro / Olovchi | столкновения замедляют вдвое слабее |

## Что где лежит

```
Assets/Scenes/Game.unity              единственная сцена: объект GameBootstrap (GameAssets + GameBootstrap)
Assets/Scripts/Localization/Loc.cs    все переводы интерфейса (ключ → русский / английский / узбекский)
Assets/Scripts/Net/                   MiniWebSocketServer, ControllerPage (страница телефона), PhoneHub, QrCode
Assets/Scripts/Game/                  GameBootstrap, PlayerWorld, PlayerAvatar, GameUI, CharacterCatalog, ...
Assets/Scripts/Game/ProceduralAssets.cs   дорога, окружение, заборы, стены, монеты, бонусы, препятствия (вместо префабов)
Assets/Scripts/Game/MeshBaker.cs          объединяет мелкие детали в один меш на материал (для FPS)
Assets/Scripts/Game/CharacterRig.cs       модели героев и анимации: бег, прыжок, приземление, удар, ожидание, взмах рукой, радость
Assets/Scripts/Pickups/PowerUp.cs         бонусы: щит, магнит, песочные часы
Assets/Scripts/Game/SynthAudio.cs         звуки и музыка (вместо аудиофайлов)
Assets/Scripts/Pickups/, Proc Gen/, Rock.cs   Pickup, Coin, Apple, Chunk, Checkpoint, Rock — как в руководстве
```

### Свои модели и префабы

Выберите объект **GameBootstrap** в сцене и перетащите свои префабы в поля компонента **GameAssets**
(King Prefab, Character Models, Chunk Prefabs, Checkpoint Chunk Prefab, Obstacle Prefabs, Music).
Заполненные поля используются вместо сгенерированных; пустые по-прежнему создаются кодом.

### Отличия от текста руководства

* Все тексты вынесены в `Loc.cs` и переведены на три языка; в меню добавлена кнопка выбора языка.
* Ввод читается через `GameInput.cs` — работает при любой настройке Active Input Handling.
* Заборы засчитываются как удар через триггер `HitSensor` (у кинематического героя Unity не присылает
  `OnCollisionEnter` со статичными объектами), препятствия помечены компонентом `Hazard`.
* В одиночной игре сохраняется рекорд.
* Если запустить Play в пустой сцене, `GameBootstrap` создастся сам.
* Исправлено: забор мог появиться прямо в точке старта и сразу ударить игрока (первые участки дороги теперь безопасны,
  первое падающее препятствие — через 2,5 с).
* Исправлено: на паузе и экране результатов полосы HUD игроков могли перекрывать меню (теперь скрываются вместе с камерами).
* Исправлено: Esc в главном меню в редакторе сразу останавливал Play Mode (теперь выход — только кнопкой «ВЫХОД»).
* Исправлено: монета/самоцвет больше не засчитываются после окончания времени.
* Исправлено: если время кончалось во время прыжка, герой оставался висеть в воздухе.
* Исправлено: удар о забор мог не засчитываться (Unity не присылает события столкновения кинематического
  героя со статичными объектами) — теперь касание проверяется самим героем каждый кадр.
* Исправлено: при ускорении угол обзора доходил до 120°, и герой становился крошечным.
* Исправлено: на телефоне-пульте при аварии в бесконечном режиме писалось «ВРЕМЯ ВЫШЛО» — теперь причина.
* Мультиплеер на Android: вместо телефонов-пультов (нужен компьютер) — гонка по Wi-Fi между телефонами.
