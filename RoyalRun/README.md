# Royal Run — мультиплеер (Unity 6000.3.26f1)

Готовый Unity-проект по руководству «Royal Run: Building from Scratch + Multiplayer»:
бесконечный раннер на 1–3 игрока, телефоны работают как джойстики по Wi-Fi.
Языки игры и страницы на телефоне: **русский, английский, узбекский**.

## Как открыть

1. Распакуйте папку `RoyalRun` в путь **без кириллицы и пробелов**, например `C:\Unity\RoyalRun`.
2. Unity Hub → **Projects** → **Add** → **Add project from disk** → выберите папку `RoyalRun`
   (ту, в которой лежат `Assets`, `Packages`, `ProjectSettings`).
3. Откройте проект в редакторе **6000.3.26f1**. Первый запуск занимает 1–5 минут: Unity скачивает пакеты.
4. Если Unity спросит про **Input System** («enable the new input backends? … restart») — нажмите **Yes**.
   Игра работает и с новой, и со старой системой ввода, так что подойдёт любой ответ.
5. Сцена `Assets/Scenes/Game` откроется сама (или меню **Royal Run → Open Game Scene**).
6. Нажмите **Play**. В окне Game включите **Maximize On Play** (и Scale = 1x).

Готовые модели, музыка и префабы из руководства (GDTV Assets, King, Blackmoor Tides) в проект **не нужны**:
герои, дорога, заборы, монеты, яблоки, падающие препятствия, звуки и музыка создаются кодом при запуске.

## Язык

В главном меню кнопка **ЯЗЫК / LANGUAGE / TIL** переключает русский → английский → узбекский.
Выбор запоминается. Страница на телефонах переключается вместе с игрой.

## Управление

| Где | Клавиши |
|---|---|
| Меню | ↑/↓ или W/S — выбор, Enter — подтвердить, мышь тоже работает, F1 — помощь с телефоном |
| Выбор героя | ←/→ — герой, Enter — играть, Esc — назад |
| Игра | WASD или стрелки — бег, **Пробел — прыжок**, Esc — пауза |
| Лобби | Tab — следующий адрес, K — игрок с клавиатуры (до 3 на одной клавиатуре), ←/→ — выбор героя, Enter — готов, L — убрать |
| Результаты | Enter — заново, L — добавить игроков / сменить героя, Esc — меню |

## Геймплей

* **Прыжок** (Пробел или короткое касание экрана телефона) — низкие красно-белые заборы можно перепрыгнуть.
  **Высокие каменные стены** перепрыгнуть нельзя — только обойти.
* **Комбо:** каждые 10 монет подряд без удара повышают множитель (x2 … x5). Удар сбрасывает комбо.
* **Очки** = монеты × множитель + 1 очко за каждый пробежанный метр.
* **Бонусы на дороге:** 🛡 щит (поглощает один удар, 10 с), 🧲 магнит (монеты летят к герою, 8 с),
  ⏳ песочные часы (+4 с). Редкий **самоцвет** в конце цепочки монет — 500 очков.
* Яблоко ускоряет, удар замедляет, чекпоинт добавляет время — как в руководстве.
* В одиночной игре сохраняется рекорд.

### Несколько игроков на одной клавиатуре

В лобби мультиплеера нажмите **K** до трёх раз. Раскладки:
игрок 1 — WASD + Пробел, игрок 2 — стрелки + правый Shift, игрок 3 — NumPad 8/4/5/6 + NumPad 0.
Можно смешивать: например, двое за клавиатурой и один с телефона.

## Игра с телефонов (мультиплеер)

1. Меню → **МУЛЬТИПЛЕЕР**. На экране появятся адрес вида `http://192.168.1.5:8080` и QR-код.
2. Телефон в **той же Wi-Fi сети**, что и компьютер → наведите камеру на QR-код.
3. Введите имя, выберите героя, нажмите **ГОТОВ**. Когда готовы все — отсчёт 3-2-1 и экран делится на 2–3 части.

Windows при первом запуске спросит про доступ к сети — разрешите **частные сети**.
Если окно закрыто, выполните в командной строке от имени администратора:

```
netsh advfirewall firewall add rule name="Royal Run" dir=in action=allow protocol=TCP localport=8080-8090
```

Подробная диагностика — клавиша **F1** в игре.

## Сборка игры

**File → Build Profiles** → Windows / macOS → **Build**. Сцена `Game` уже добавлена в список сцен.

## Что где лежит

```
Assets/Scenes/Game.unity              единственная сцена: объект GameBootstrap (GameAssets + GameBootstrap)
Assets/Scripts/Localization/Loc.cs    все переводы интерфейса (ключ → русский / английский / узбекский)
Assets/Scripts/Net/                   MiniWebSocketServer, ControllerPage (страница телефона), PhoneHub, QrCode
Assets/Scripts/Game/                  GameBootstrap, PlayerWorld, PlayerAvatar, GameUI, CharacterCatalog, ...
Assets/Scripts/Game/ProceduralAssets.cs   дорога, окружение, заборы, стены, монеты, бонусы, препятствия (вместо префабов)
Assets/Scripts/Game/MeshBaker.cs          объединяет мелкие детали в один меш на материал (для FPS)
Assets/Scripts/Game/CharacterRig.cs       модели героев и анимации: бег, прыжок, приземление, удар, ожидание, взмах рукой, радость
Assets/Scripts/Pickups/PowerUp.cs         бонусы: щит, магнит, песочные часы
Assets/Scripts/Game/SynthAudio.cs         звуки и музыка (вместо аудиофайлов)
Assets/Scripts/Pickups/, Proc Gen/, Rock.cs   Pickup, Coin, Apple, Chunk, Checkpoint, Rock — как в руководстве
```

### Свои модели и префабы

Выберите объект **GameBootstrap** в сцене и перетащите свои префабы в поля компонента **GameAssets**
(King Prefab, Character Models, Chunk Prefabs, Checkpoint Chunk Prefab, Obstacle Prefabs, Music).
Заполненные поля используются вместо сгенерированных; пустые по-прежнему создаются кодом.

### Отличия от текста руководства

* Все тексты вынесены в `Loc.cs` и переведены на три языка; в меню добавлена кнопка выбора языка.
* Ввод читается через `GameInput.cs` — работает при любой настройке Active Input Handling.
* Заборы засчитываются как удар через триггер `HitSensor` (у кинематического героя Unity не присылает
  `OnCollisionEnter` со статичными объектами), препятствия помечены компонентом `Hazard`.
* В одиночной игре сохраняется рекорд.
* Если запустить Play в пустой сцене, `GameBootstrap` создастся сам.
* Исправлено: забор мог появиться прямо в точке старта и сразу ударить игрока (первые участки дороги теперь безопасны,
  первое падающее препятствие — через 2,5 с).
* Исправлено: на паузе и экране результатов полосы HUD игроков могли перекрывать меню (теперь скрываются вместе с камерами).
* Исправлено: Esc в главном меню в редакторе сразу останавливал Play Mode (теперь выход — только кнопкой «ВЫХОД»).
* Исправлено: монета/самоцвет больше не засчитываются после окончания времени.
