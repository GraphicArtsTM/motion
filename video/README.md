# Muhr — промо-ролик (1080×1350, 32 с, 60 fps)

Рекламный моушн-ролик для гарант-платёжки **Muhr**. Всё собрано из элементов прототипа
`garant-pay13.html`: палитра «глазурь Регистана», шрифты Unbounded и Rubik, печать-звезда с замком,
плитки со срезанными углами, лента гирих, карточки сделок, кошелёк, экран перевода.

Готовое видео: `out/muhr-promo-1080x1350.mp4`.

## Сценарий (120 BPM, сцены на тактовой сетке)

| Время | Сцена | Что происходит |
|---|---|---|
| 0–4 с | Хук | «Покупаешь у незнакомца?», переписка с продавцом «переведи всё вперёд», карточка «Высокий риск», глитч и схлопывание |
| 4–8 с | Бренд | Удар: золотая печать-звезда, замок защёлкивается, кольца и частицы, «Muhr — Платежи с гарантом» |
| 8–12 с | Дроп | Телефон влетает в 3D, кошелёк считает баланс, всплывают фичи: деньги под замком, выплата после подтверждения, спор решает арбитр |
| 12–16 с | Под замком | Деньги летят от покупателя в сейф, замок закрывается, сумма 8 463 000 сўм |
| 16–20 с | Как работает | Четыре шага гаранта, лента гирих зажигается, «Сделка завершена» |
| 20–24 с | Сделки | Карточки сделок прилетают из глубины, печать «Выплачено» |
| 24–28 с | Перевод | Набор суммы на клавиатуре в ритм, свайп, «Перевод отправлен» |
| 28–32 с | Финал | Печать, логотип, слоган, кнопка «Начать сделку» |

## Музыка

`music.py` синтезирует трек целиком на numpy, без сэмплов: 120 BPM, ре гармонический минор,
бочка/клэп/хэты, дойра, щипковый «дутар» (Karplus–Strong), бас с сайдчейном, пэды, райзеры и удары.
Звуки привязаны к событиям в кадре: щелчок замка, монеты, «динь» на каждом шаге, клики клавиш,
свайп, удар печати. Громкость нормализуется до −14 LUFS.

## Сборка

Нужны Node.js с Playwright (Chromium), Python 3 с numpy и ffmpeg.

```bash
./build.sh                                  # музыка → кадры → out/muhr-promo-1080x1350.mp4
node render.mjs --stills 4.3,9.6,22.6       # стоп-кадры для проверки в out/stills/
```

Предпросмотр в браузере: открыть `index.html` (проигрывается по кругу) или `index.html?t=12.5` (стоп-кадр).
Всё движение — в `motion.js`, функция `renderAt(t)` детерминированно рисует кадр для момента `t`.
