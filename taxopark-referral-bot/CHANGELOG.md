# CHANGELOG

## 1.0.0 — 2026-10-25

Первая поставка по ТЗ v6.0.

### Добавлено
- Схема БД раздела 10 (миграция `0001`, порядок по зависимостям, E1) и сиды Приложения 18.1 (`0002`);
  дополнения: outbox уведомлений, курсоры синхронизации, учётные записи веб-панели, заметки, белый список
  антифрода, неизменяемый audit log.
- Ядро: атрибуция с метками каналов (A1, N4), регистрация и автопроверка с проверкой окна клика (A2, E5),
  модерация (A3), периоды со снимком коэффициентов и `ensure_current_period` (A4, E4), подсчёт баллов (A5),
  закрытие периода с бюджетом, welcome-бонусом и достижениями (A6, N1, N7), пересчёт закрытого периода (A17, E3),
  кошелёк с долгом (A9, E2), вывод со сверкой и ручной выплатой уволенным (A10, A11, E6), синхронизации (A12–A14),
  симулятор (A15), режим отображения прогресса (A16), дедупликация уведомлений (A18, E8), антифрод с формулой
  IMPOSSIBLE_HOURS (E7), оспаривание с детализацией (N6), условия с версиями (N3).
- Fleet: `ApiFleetProvider`, `CsvFleetProvider`, `ManualFleetProvider`, `MockFleetProvider`; три класса ошибок;
  circuit breaker; журнал `api_sync_log`.
- Telegram-бот (aiogram 3): регистрация, экраны раздела 7, access/terms-gate, Telegram-админка, доставка outbox.
- Веб: admin API с RBAC и 2FA, SQLAdmin, вебхук с проверкой `secret_token`, `/health`.
- Воркеры ARQ: 24 задачи раздела 11 с `job_locks` и алертами.
- Локали `uz_latn`, `uz_cyrl`, `ru`.
- Docker / docker-compose / nginx, CI, скрипты: Шаг 0 (`api_recon`), создание админа, бэкап-проверка, Postman.
- 180+ автотестов (кейсы раздела 16, e2e бота, API, воркеры, нагрузка).

### Известные ограничения
- Шаг 0 (разведка Fleet API) не выполнен — нужен доступ к реальному парку (см. README).
- Узбекская кириллица сгенерирована транслитерацией, нужна вычитка.
