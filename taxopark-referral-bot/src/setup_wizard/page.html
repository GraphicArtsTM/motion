🚕 Настройка реферального бота

Заполните шаги по порядку — каждую часть можно сразу проверить кнопкой. После «Сохранить» окно закроется, а запуск продолжится автоматически. Мастер можно открыть снова в любой момент: setup.bat.

1Telegram-бот

Где взять токен
  1. Откройте в Telegram @BotFather → /newbot → придумайте имя и username (на конце bot).
  2. BotFather пришлёт токен вида 123456789:AAH… — вставьте его ниже.
  3. Рекомендуем там же: /setjoingroups → Enable (для админ-чата), /setdescription — описание.

2Администраторы и админ-чат

Сюда будут приходить заявки на подключение, выводы, обращения и алерты.

  1. Откройте своего бота в Telegram и отправьте ему /start (каждый администратор — со своего аккаунта).
  2. Для общего админ-чата: создайте группу, добавьте туда бота и напишите в группе /start@имя_бота.
  3. Нажмите «Найти» — мастер покажет, кто писал боту.

Если не указать — уведомления придут администраторам в личку.

3API таксопарка (Яндекс Fleet)

Где взять ключ и какие доступы отметить
  1. Кабинет парка fleet.yandex.ru → Настройки → API (ключи API) → Создать ключ. Создайте отдельный ключ только для бота.
  2. Отметьте доступы только к методам из таблицы ниже: обязательные — для работы, желательные — для тарифа по авто, антифрода и карточки водителя. Больше ничего не включайте (создание/изменение профилей и авто, гараж, курьеры, заправки, «[Устаревший]» методы — не нужны).
  3. Скопируйте Client ID (вида taxi/park/…), API-ключ и ID парка (есть в адресной строке кабинета и в разделе API).
Метод в кабинетеДоступЗачем
Подключить API — проверка друзей по базе, баллы по заказам и автоматический вывод денег.
Пока без API — бот запустится, но привязку профилей и выплаты администратор делает вручную.

Адрес API (менять не нужно)

Проверка ничего не меняет в парке: методы чтения вызываются с ограничением в 1 запись, выплата — заведомо неверным запросом без списания денег.

4Таксопарк и выплаты

Можно использовать <b>жирный</b> и ссылки. Суммы, пороги и коэффициенты меняются потом в админке.

Автоматически — по кнопке «Вывести» деньги сразу уходят на баланс Яндекс Про.
С подтверждением менеджера — каждая заявка ждёт кнопки в админ-чате.

6Где работает бот

На этом компьютере — домен и HTTPS не нужны. Бот работает, пока включён компьютер и запущен Docker.
Сервер с доменом — рекомендуемо для работы 24/7. Нужен домен, направленный на сервер (A-запись), порты 80 и 443. Сервер с базой должен находиться в Узбекистане (закон о ПД).
