# Фронтир

Пиксельная 2D онлайн-стратегия для Roblox. Дизайн-документ: [`docs/GDD.md`](docs/GDD.md).

## Что понадобится
- [Roblox Studio](https://create.roblox.com/)
- [Git](https://git-scm.com/)
- [Rokit](https://github.com/rojo-rbx/rokit) — ставит остальные инструменты (Rojo, Lune, StyLua, Selene, luau-lsp) нужных версий из `rokit.toml`.
- Желательно: VS Code с расширениями из `.vscode/extensions.json` (luau-lsp, StyLua, Selene, Rojo).

## Установка

### Windows
1. Установи Rokit в PowerShell:
   ```powershell
   Invoke-RestMethod https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.ps1 | Invoke-Expression
   ```
   (или скачай `rokit.exe` со страницы [релизов](https://github.com/rojo-rbx/rokit/releases) и выполни `rokit.exe self-install`). Перезапусти терминал.
2. Склонируй репозиторий и поставь инструменты:
   ```powershell
   git clone <url-репозитория>
   cd motion\frontir
   rokit install
   ```
   На вопрос о доверии инструментам ответь «да».
3. Поставь плагин Rojo в Studio:
   ```powershell
   rojo plugin install
   ```

### Mac
1. Установи Rokit:
   ```bash
   curl -sSf https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.sh | bash
   ```
   Перезапусти терминал.
2. Склонируй репозиторий и поставь инструменты:
   ```bash
   git clone <url-репозитория>
   cd motion/frontir
   rokit install
   ```
3. Плагин Rojo для Studio:
   ```bash
   rojo plugin install
   ```

## Проверка этапа в Studio
Делается после каждого этапа. Все команды выполняются в папке `frontir/`.

1. Поставь или обнови инструменты проекта (после каждого `git pull` тоже):
   ```bash
   rokit install
   ```
2. Поставь плагин Rojo в Studio (один раз, и после обновления версии Rojo):
   ```bash
   rojo plugin install
   ```
3. Запусти синхронизацию и не закрывай терминал:
   ```bash
   rojo serve
   ```
4. Открой Roblox Studio → пустой **Baseplate**. Вкладка **Plugins → Rojo → Connect** (адрес по умолчанию `localhost:34872`).
5. Нажми **Play** (или **Test → Clients and Servers → 2 Players**, когда этап про мультиплеер).
6. Сверь увиденное с разделом «Как проверить в Studio» из отчёта по этапу.

**Этап 1:** на весь экран — карта «Пангея» (один материк, горы со снежными вершинами, реки, озёра, тундра у полюсов),
на воде мерцают блики. Карта сразу занимает почти весь экран. В Studio справа сверху (под панелью Roblox) открыто окно
отладки (F3 — скрыть/показать): FPS, зум, клетка под курсором, память EditableImage. Управление:
- колесо мыши — плавный зум к курсору: от «всей карты» до ×12; от ×2 зум встаёт только на целые значения,
  чтобы все клетки были одного размера;
- зажатая правая или средняя кнопка — тащить карту; WASD и стрелки — прокрутка; Space — показать всю карту;
- телефон (Test → Device Emulator или реальное устройство): палец — тащить, щипок — зум.

В Output: `[Frontir] server: карта Pangea 512×320, …` и `[Frontir] client: карта Pangea 512×320, чанков 4`.

**Этап 2:** **Test → Clients and Servers → 2 Players → Start** (откроются окно сервера и два окна игроков).
1. 20 секунд — выбор точки старта: нажми левой кнопкой (или пальцем) на свободную сушу. Сверху таймер; выбор
   другого игрока видно белым квадратом с именем. Слишком близко к чужому старту или на воду — сервер откажет,
   внизу слева появится причина. Можно перевыбрать.
2. После таймера — 6 держав: 2 игрока + 4 бота (выдуманные имена). У каждой свой цвет и тёмная граница,
   цвета ближайших соседей разные. Боты через 1–2 секунды начинают расширяться.
3. Слева внизу ползунок «Атака N%» (−/+ или тащить полосу). Нажми на ничью землю рядом со своей границей —
   граница поползёт в сторону нажатия, свежие клетки вспыхивают. Появится строка атаки с числом людей и кнопкой ×
   (отмена — оставшиеся люди возвращаются). Нажатие на соседнюю державу — война с ней.
4. Слева сверху — люди / максимум, прирост в секунду, доля суши; справа сверху — лидеры.
5. Сравни два окна игроков: границы одинаковые. В F3 — время тика сервера, клеток за тик и пинг.

**Этап 3а:** то же **Test → 2 Players**. *(С этапа 3б пункты 2–5 устарели: отрядов на карте больше нет — см. «Этап 3б».)*
1. На карте тонкие, едва заметные линии — границы провинций. Квадраты с белой точкой — нейтральные города,
   квадрат с подписью — столица (своя — с золотой обводкой). Space — камера к своей столице.
2. Снизу по центру — карточки найма: Пехота / Танки / Артиллерия (клавиши 1–3; на узком экране — справа).
   Цена в людях и время найма. Армия появляется в столице с серым кольцом найма.
3. Нажми на свою армию (Shift — добавить к выделению; на ПК можно рамкой левой кнопкой) — справа панель:
   тип, сила, состояние, кнопки «Стоп», «Авто», «Снять» (Esc тоже снимает).
4. С выделенной армией нажми на карту — армия идёт туда (обходит воду, горы по возможности). Придя, она заливает
   провинцию своим цветом кругом от себя, вокруг армии голубое кольцо прогресса. Провинция с чужим городом — вдвое дольше.
5. Ползущая граница (ползунок атаки) города не берёт — только армии. «Авто» — армия сама идёт в соседние
   непокорённые провинции (сначала города). Армии ботов работают в «авто».

**Этап 3б:** то же **Test → 2 Players**. Отряды больше не водят по карте: войска — это сила державы, они воюют фронтами.
1. Снизу по центру — карточки найма: Пехота / Танки / Артиллерия / ПВО (клавиши **Z / X / C / V**; на узком экране —
   справа в две строки). Цена в людях и время; «+N» — сколько таких в очереди.
2. Справа — панель «Войска»: дома и на фронтах, по типам — сила дома · на фронтах, ★ — звёзды ветеранов, очередь найма.
3. Найми несколько юнитов, поставь ползунок «Атака» на 40–60% и нажми на соседнюю державу. Слева снизу появится
   строка фронта: цель, сила, «перевес ×N» (красным «стоит», если перевеса нет). Вдоль общей границы встанут твои
   юниты (их состав — как у фронта), напротив — защитники; пока идёт бой, на линии вспыхивают выстрелы и рвутся снаряды.
   Сильный фронт ползёт и берёт города, слабый стоит и тает. Без войск напасть на державу нельзя — внизу слева подсказка.
4. Уйди фронтом далеко от своих городов — юниты фронта получат красную обводку, в строке — «нет снабжения».
5. Держава, у которой пал последний город, выбывает: её земля становится ничьей, внизу слева сообщение.
6. F3: «Сеть: X КБ/с» (сколько принимает этот клиент) и «Фронтов: N, в бою M».
7. Карту теперь можно тащить и левой кнопкой мыши.

**Этап 3в:** то же **Test → 2 Players**.
1. Между странами мир. Нажми на соседнюю страну — появится окно с её названием и «Объявить войну».
   Без войны атаковать страну нельзя: граница людей идёт только на ничью землю.
2. «Объявить войну» → у обоих игроков сверху баннер «МОБИЛИЗАЦИЯ: A — B · 15 с», внизу слева строка в ленте
   (у того, на кого напали, — красная, баннер мигает; в Output — «звук (заглушка): Siren»). Пока идёт
   мобилизация, атака отклоняется.
3. После мобилизации — «ВОЙНА: A — B»: полоска перевеса в цветах стран, взятая земля и потери обеих сторон.
   Найми войска (Z/X/C/V) и нажми на вражескую землю: туда пойдёт главный удар, там юнитов больше.
   «К фронту» — камера на линию фронта.
4. Приблизь бой (×4 и ближе): войска двух сторон стоят друг против друга через ничейную полосу, пехота
   сходится, танки выезжают, артиллерия сзади бьёт снарядами по дуге, остаются воронки и дым (20 с),
   погибшие юниты разлетаются пикселями. Бой через реку идёт медленнее, защитнику на берегу легче.
5. «Мир» → «Белый мир» (взятая земля вернётся) или «Забрать захваченное». У второго игрока — окно с предложением,
   «Принять» / «Отклонить», 20 с. После мира минуту нельзя снова объявить войну этой стране («Мир: ещё N с»).
6. Захват ничьей земли: нажми на ничью землю — растёт вся граница, сторона клика быстрее, дыр не остаётся.
7. Через 5 минут войны в панели державы — «Усталость от войны: −N% прироста».

**Этап 4а:** **Test → 2 Players**. Карта по умолчанию — «Европа» (`Config.Match.DefaultMap`); другую можно поставить
в `Config.Dev.Map` (`"World"`, `"Mediterranean"`, `"Asia"`, `"Americas"`, `"Africa"`).
1. На экране — настоящие очертания: берега, Альпы, Скандинавия, Чёрное и Каспийское моря, реки. Тундра на севере,
   тайга, степи и пустыни на юге. В Output: `[Frontir] server: карта Europe 768×576, …`.
2. В Explorer: все карты — в `ServerStorage.Maps`, у игроков в `ReplicatedStorage.Maps` только выбранная.
3. Выбор старта, расширение, войны — как раньше; провинции называются по географии («Альпы-2», «Карпаты-1»).
4. Поставь `Config.Dev.Map = "World"` и проверь самую большую карту (1024×512): FPS в F3, плавность зума.

**Этап 4б:** **Test → 2 Players**, карта «Европа».
1. Слева сверху — «Деньги: 4 000 (+N/с)» и «Нефть: 0 (+0/с)». Деньги растут с земли и городов.
2. Карточки найма показывают цену: пехота $1 000; танки, артиллерия и ПВО — «нужен завод».
3. «Построить (B)» над карточками → «Завод» → нажми свою провинцию: в её центре появится значок завода,
   деньги спишутся, танки станут доступны (цена в деньгах и нефти).
4. Тёмные капли на карте — нефтяные поля. Возьми такую провинцию и поставь «Нефтяную вышку» — пойдёт нефть.
5. «Город +1 уровень» → нажми свою столицу: рядом появится золотая точка, вырастут доход и максимум людей.
6. «Укрепление» в провинции у границы врага: фронт там идёт тяжелее. Если фронт стоит минуту — защитнику ещё легче.
7. Котёл: отрежь кусок вражеской земли без города от его столицы (во время войны) — через 30 с он сдастся.
8. Нанимай много войск без денег — в панели станет «−N/с», а при нуле денег войска начнут таять.

**Этап 4в:** **Test → 2 Players**, карта «Европа» (для быстрой проверки поставь в `Config.Match` меньше
`TimeLimitSec`, например `3 * 60`, и `LobbySec = 5`).
1. Первый игрок заходит — баннер «Лобби · Европа · старт через N с», «Игроков: 2 · держав в матче: 12».
2. Через 20 с — выбор старта, потом игра: в баннере таймер до конца (цифры Arcade), «держав: N» и полоса лидера его цветом.
3. Справа снизу — мини-карта: цвета держав, золотая рамка камеры. Нажми или потяни по ней — камера едет туда.
   F3 — над мини-картой.
4. Конец матча (60% суши, последняя держава или время вышло): окно «Победа: держава» цветом победителя, причина,
   «Ваше место: N из M», места, график доли суши. «Смотреть карту» прячет окно, «Итоги» возвращает.
5. Через 20 с — снова лобби на той же карте, карта очищена, у обоих окон одинаково.
6. Телефон (Device Emulator): карточки найма и «Построить» — слева от мини-карты, окно итогов ужимается под экран.

**Этап 5:** боты v2. В `src/shared/Config.luau` → `Config.Dev` поставь `BotLevel = "General"` и `Nations = 4`
(ты + 3 Генерала), карта «Европа», **Test → 1 Player** (или 2 Players). Потом то же с `BotLevel = "Novice"`.
1. В таблице лидеров справа сверху у ботов серая метка «бот·Генерал» (или «бот·Новичок»).
2. Нажми на соседа — в окне «Объявить войну» видно его уровень и личность (например «бот·Генерал, Агрессор»).
3. Генералы быстро строят завод и укрепления у границы, нанимают войска против твоего состава (много танков —
   у них появится артиллерия), бьют в ближайший город, отменяют проигранные фронты, нападают на лидера.
4. Против трёх Генералов удержаться трудно; против трёх Новичков — легко: они копят, лезут в войну наобум и редко
   строят.
5. Верни `BotLevel = ""` и `Nations = 0` — обычный матч: уровни по `Config.Bots.LevelMix`.

**Этап 6а:** договоры. **Test → 1 Player**, `Config.Dev.Nations = 6`, карта «Европа».
1. Нажми **T** (или «Дипломатия (T)» внизу) — окно со всеми державами: отношение с вами, примерная сила, метки.
2. Выбери соседа-бота → «Союз». Если у бота есть общая угроза или вы сильнее — он примет (лента: «… — союз»),
   иначе откажет. Пакт на 3 или 5 минут боты принимают охотнее.
3. Предательство: союзнику нажми «Объявить войну» → «Объявить». В ленте «… предала …», у вашего имени
   на карте и в таблице лидеров — красная «⚠ Предатель» на 5 минут; боты больше не берут вас в союзы.
4. «Разорвать» союз — через 15 с союз кончится без метки; разорвать пакт раньше срока — метка через 15 с.
5. «Требование» → нажми провинцию соседа у вашей границы (не со столицей). Слабый бот отдаст её,
   сильный откажет — и сразу начнётся мобилизация.
6. Войска меньше трети врага — в окне мира «Капитуляция»: станете вассалом (20% дохода сюзерену);
   через 5 минут — кнопка «Независимость» в окне дипломатии.
7. Боты сами шлют вам предложения: окно сверху с таймером «Принять / Отказать».

**Этап 6б:** Совет и торговля. **Test → 2 Players**, `Config.Dev.Nations = 6`; для быстрой проверки Совета
поставь `Config.Council.EverySec = 60`.
1. Окно дипломатии (T) → сосед → «Торговля +5%»: бот примет — у обоих «торговля», доход +5%.
2. «+1 000 $» / «+50 нефти» / «+300 людей» — перевод; второму окну придёт «… передала вам …» (минус 10% налога).
   Много раз подряд — «Лимит переводов за минуту». «Эмбарго» — переводы и соглашение пропадают.
3. Через 6 минут (или 60 с) сверху — «Совет держав»: три резолюции, таймер 30 с, голоса ботов видны сразу.
   Нажми вариант — «▶» и «Ваш голос учтён». После голосования — лента «Совет принял: …»
   и строка «Действует: …» под баннером (санкции, перемирие, свободная торговля).
4. «Пинг (G)» → «Помоги здесь!» → нажми на карту: в обоих окнах метка с фразой на 6 с и строка в ленте.

**Публикация.** EditableImage в опубликованной игре по умолчанию выключен. Включи его один раз:
Studio → **File → Experience Settings → Security → Allow Mesh / Image APIs** (или Creator Dashboard → Configure → Settings).
Иначе на экране будет сообщение об ошибке вместо карты.

> Персонажи отключены (`Players.CharacterAutoLoads = false`): игра 2D и аватар не нужен.

Из папки `frontir/` — то же самое, что делает CI (`.github/workflows/ci.yml` в корне репозитория):
```bash
lune run tests
```
```bash
stylua --check src tests tools
```
```bash
selene src tests tools
```
Проверка типов (strict). Первые две команды нужны один раз и после изменения структуры файлов:
```bash
lune setup
```

```bash
rojo sourcemap default.project.json -o sourcemap.json
```
```bash
luau-lsp analyze --platform=roblox --definitions:@roblox=types/globalTypes.d.luau --sourcemap=sourcemap.json --base-luaurc=.luaurc src tests tools
```

### Карты
В игре — только карты с реальной географией: «Мир», «Европа», «Средиземноморье», «Азия», «Америки», «Африка»
(`Config.RealMaps`). Их собирает `tools/realmap` из открытых данных и пишет в `maps/<Имя>.luau`:
```bash
lune run tools/realmap all
```
Одну карту — `lune run tools/realmap Europe`. При первом запуске данные скачиваются в `build/geo/` (в git не идут),
превью каждой карты — `build/<Имя>.png`, лист всех карт — `lune run tools/maps_preview`.

Данные карт:
- **Natural Earth** 1:50m (naturalearthdata.com, public domain): суша, озёра, реки, географические регионы.
- **ETOPO1** (NOAA NGDC, Amante & Eakins 2009, свободное использование) через ERDDAP (coastwatch.pfeg.noaa.gov):
  высоты.
Реальных стран, границ и столиц на картах нет; имена провинций — от гор, равнин, пустынь и полуостровов,
подписи с названиями стран отбрасываются.

Тестовая выдуманная карта «Пангея» генерируется по сиду из `Config.MapGen.Pangea`: `lune run tools/genmap Pangea`
(превью `build/Pangea.bmp`). Тест `MapFormat.spec` падает, если закоммиченная карта не совпадает с генератором.

### Нагрузка сервера
`lune run tools/bench World 60 180` — партия 60 ботов на «Мире»: время тика (в Lune на этой машине) и трафик на клиента.

### Арена ботов
`lune run tools/bot_arena Europe 4` — «игрок» (Обычный бот) против трёх Новичков, Обычных и Генералов, 4 сида
(≈ 8 минут). Печатает место и долю суши «игрока». Только один уровень: `lune run tools/bot_arena Europe 2 General`.

### Превью партии
```bash
lune run tools/match_preview 120
```
Прогоняет 120 секунд партии ботов и пишет `build/match.png` — теми же функциями, что рисует клиент.
Превью этапов лежат в `docs/previews/` (третий аргумент — путь к файлу).

### Русский интерфейс при английском Roblox
В `src/shared/Config.luau` поставь `Config.Dev.ForceLang = "ru"` (пустая строка — язык Roblox).

### Обновление определений Roblox
Определения для selene (`roblox.yml`) и luau-lsp (`types/globalTypes.d.luau`) закоммичены, чтобы проверки работали одинаково локально и в CI без сети.
Обновлять, когда в Roblox появились нужные новые API:
```bash
selene generate-roblox-std
```
```bash
curl -sSfL -o types/globalTypes.d.luau https://raw.githubusercontent.com/JohnnyMorganz/luau-lsp/1.70.1/scripts/globalTypes.d.luau
```
(в ссылке — версия luau-lsp из `rokit.toml`).

## Автодополнение (luau-lsp)
```bash
rojo sourcemap default.project.json -o sourcemap.json
```
```bash
lune setup
```
Первая команда даёт luau-lsp карту Roblox-инстансов, вторая — типы модулей Lune (алиас `@lune` в `.luaurc`).

## Структура
```
src/shared   чистая логика + Config + типы (тестируется в Lune)
src/server   серверные скрипты
src/client   клиент: рендер, UI, ввод
maps/        упакованные карты
tools/       Lune-скрипты (генерация карт)
tests/       Lune-тесты (*.spec.luau)
docs/        GDD, список арта, баланс, changelog
types/       определения Roblox для luau-lsp
roblox.yml   определения Roblox для selene
```
