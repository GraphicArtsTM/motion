# Фронтир

Пиксельная 2D онлайн-стратегия для Roblox. Дизайн-документ: [`docs/GDD.md`](docs/GDD.md).

## Что понадобится
- [Roblox Studio](https://create.roblox.com/)
- [Git](https://git-scm.com/)
- [Rokit](https://github.com/rojo-rbx/rokit) — ставит остальные инструменты (Rojo, Lune, StyLua, Selene, luau-lsp) нужных версий из `rokit.toml`.
- Желательно: VS Code с расширениями из `.vscode/extensions.json` (luau-lsp, StyLua, Selene, Rojo).

## Установка

### Windows
1. Установи Rokit в PowerShell:
   ```powershell
   Invoke-RestMethod https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.ps1 | Invoke-Expression
   ```
   (или скачай `rokit.exe` со страницы [релизов](https://github.com/rojo-rbx/rokit/releases) и выполни `rokit.exe self-install`). Перезапусти терминал.
2. Склонируй репозиторий и поставь инструменты:
   ```powershell
   git clone <url-репозитория>
   cd motion\frontir
   rokit install
   ```
   На вопрос о доверии инструментам ответь «да».
3. Поставь плагин Rojo в Studio:
   ```powershell
   rojo plugin install
   ```

### Mac
1. Установи Rokit:
   ```bash
   curl -sSf https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.sh | bash
   ```
   Перезапусти терминал.
2. Склонируй репозиторий и поставь инструменты:
   ```bash
   git clone <url-репозитория>
   cd motion/frontir
   rokit install
   ```
3. Плагин Rojo для Studio:
   ```bash
   rojo plugin install
   ```

## Проверка этапа в Studio
Делается после каждого этапа. Все команды выполняются в папке `frontir/`.

1. Поставь или обнови инструменты проекта (после каждого `git pull` тоже):
   ```bash
   rokit install
   ```
2. Поставь плагин Rojo в Studio (один раз, и после обновления версии Rojo):
   ```bash
   rojo plugin install
   ```
3. Запусти синхронизацию и не закрывай терминал:
   ```bash
   rojo serve
   ```
4. Открой Roblox Studio → пустой **Baseplate**. Вкладка **Plugins → Rojo → Connect** (адрес по умолчанию `localhost:34872`).
5. Нажми **Play** (или **Test → Clients and Servers → 2 Players**, когда этап про мультиплеер).
6. Сверь увиденное с разделом «Как проверить в Studio» из отчёта по этапу.

**Этап 1:** на весь экран — карта «Пангея» (один материк, горы со снежными вершинами, реки, озёра, тундра у полюсов),
на воде мерцают блики. Карта сразу занимает почти весь экран. В Studio справа сверху (под панелью Roblox) открыто окно
отладки (F3 — скрыть/показать): FPS, зум, клетка под курсором, память EditableImage. Управление:
- колесо мыши — плавный зум к курсору: от «всей карты» до ×12; от ×2 зум встаёт только на целые значения,
  чтобы все клетки были одного размера;
- зажатая правая или средняя кнопка — тащить карту; WASD и стрелки — прокрутка; Space — показать всю карту;
- телефон (Test → Device Emulator или реальное устройство): палец — тащить, щипок — зум.

В Output: `[Frontir] server: карта Pangea 512×320, …` и `[Frontir] client: карта Pangea 512×320, чанков 4`.

**Этап 2:** **Test → Clients and Servers → 2 Players → Start** (откроются окно сервера и два окна игроков).
1. 20 секунд — выбор точки старта: нажми левой кнопкой (или пальцем) на свободную сушу. Сверху таймер; выбор
   другого игрока видно белым квадратом с именем. Слишком близко к чужому старту или на воду — сервер откажет,
   внизу слева появится причина. Можно перевыбрать.
2. После таймера — 6 держав: 2 игрока + 4 бота (выдуманные имена). У каждой свой цвет и тёмная граница,
   цвета ближайших соседей разные. Боты через 1–2 секунды начинают расширяться.
3. Слева внизу ползунок «Атака N%» (−/+ или тащить полосу). Нажми на ничью землю рядом со своей границей —
   граница поползёт в сторону нажатия, свежие клетки вспыхивают. Появится строка атаки с числом людей и кнопкой ×
   (отмена — оставшиеся люди возвращаются). Нажатие на соседнюю державу — война с ней.
4. Слева сверху — люди / максимум, прирост в секунду, доля суши; справа сверху — лидеры.
5. Сравни два окна игроков: границы одинаковые. В F3 — время тика сервера, клеток за тик и пинг.

**Этап 3а:** то же **Test → 2 Players**. *(С этапа 3б пункты 2–5 устарели: отрядов на карте больше нет — см. «Этап 3б».)*
1. На карте тонкие, едва заметные линии — границы провинций. Квадраты с белой точкой — нейтральные города,
   квадрат с подписью — столица (своя — с золотой обводкой). Space — камера к своей столице.
2. Снизу по центру — карточки найма: Пехота / Танки / Артиллерия (клавиши 1–3; на узком экране — справа).
   Цена в людях и время найма. Армия появляется в столице с серым кольцом найма.
3. Нажми на свою армию (Shift — добавить к выделению; на ПК можно рамкой левой кнопкой) — справа панель:
   тип, сила, состояние, кнопки «Стоп», «Авто», «Снять» (Esc тоже снимает).
4. С выделенной армией нажми на карту — армия идёт туда (обходит воду, горы по возможности). Придя, она заливает
   провинцию своим цветом кругом от себя, вокруг армии голубое кольцо прогресса. Провинция с чужим городом — вдвое дольше.
5. Ползущая граница (ползунок атаки) города не берёт — только армии. «Авто» — армия сама идёт в соседние
   непокорённые провинции (сначала города). Армии ботов работают в «авто».

**Этап 3б:** то же **Test → 2 Players**. Отряды больше не водят по карте: войска — это сила державы, они воюют фронтами.
1. Снизу по центру — карточки найма: Пехота / Танки / Артиллерия / ПВО (клавиши **Z / X / C / V**; на узком экране —
   справа в две строки). Цена в людях и время; «+N» — сколько таких в очереди.
2. Справа — панель «Войска»: дома и на фронтах, по типам — сила дома · на фронтах, ★ — звёзды ветеранов, очередь найма.
3. Найми несколько юнитов, поставь ползунок «Атака» на 40–60% и нажми на соседнюю державу. Слева снизу появится
   строка фронта: цель, сила, «перевес ×N» (красным «стоит», если перевеса нет). Вдоль общей границы встанут твои
   юниты (их состав — как у фронта), напротив — защитники; пока идёт бой, на линии вспыхивают выстрелы и рвутся снаряды.
   Сильный фронт ползёт и берёт города, слабый стоит и тает. Без войск напасть на державу нельзя — внизу слева подсказка.
4. Уйди фронтом далеко от своих городов — юниты фронта получат красную обводку, в строке — «нет снабжения».
5. Держава, у которой пал последний город, выбывает: её земля становится ничьей, внизу слева сообщение.
6. F3: «Сеть: X КБ/с» (сколько принимает этот клиент) и «Фронтов: N, в бою M».
7. Карту теперь можно тащить и левой кнопкой мыши.

**Публикация.** EditableImage в опубликованной игре по умолчанию выключен. Включи его один раз:
Studio → **File → Experience Settings → Security → Allow Mesh / Image APIs** (или Creator Dashboard → Configure → Settings).
Иначе на экране будет сообщение об ошибке вместо карты.

> Персонажи отключены (`Players.CharacterAutoLoads = false`): игра 2D и аватар не нужен.

## Тесты и проверки
Из папки `frontir/` — то же самое, что делает CI (`.github/workflows/ci.yml` в корне репозитория):
```bash
lune run tests
```
```bash
stylua --check src tests tools
```
```bash
selene src tests tools
```
Проверка типов (strict). Первые две команды нужны один раз и после изменения структуры файлов:
```bash
lune setup
```
```bash
rojo sourcemap default.project.json -o sourcemap.json
```
```bash
luau-lsp analyze --platform=roblox --definitions:@roblox=types/globalTypes.d.luau --sourcemap=sourcemap.json --base-luaurc=.luaurc src tests tools
```

### Карты
Выдуманные карты генерируются по сиду из параметров `Config.MapGen.<Имя>` и упаковываются в `maps/<Имя>.luau`:
```bash
lune run tools/genmap Pangea
```
Заодно пишется превью `build/Pangea.bmp` (в git не идёт). Тест `MapFormat.spec` падает, если закоммиченная карта
не совпадает с генератором — после правки параметров карты перезапусти команду выше.

### Превью партии
```bash
lune run tools/match_preview 120
```
Прогоняет 120 секунд партии ботов и пишет `build/match.png` — теми же функциями, что рисует клиент.
Превью этапов лежат в `docs/previews/` (третий аргумент — путь к файлу).

### Русский интерфейс при английском Roblox
В `src/shared/Config.luau` поставь `Config.Dev.ForceLang = "ru"` (пустая строка — язык Roblox).

### Обновление определений Roblox
Определения для selene (`roblox.yml`) и luau-lsp (`types/globalTypes.d.luau`) закоммичены, чтобы проверки работали одинаково локально и в CI без сети.
Обновлять, когда в Roblox появились нужные новые API:
```bash
selene generate-roblox-std
```
```bash
curl -sSfL -o types/globalTypes.d.luau https://raw.githubusercontent.com/JohnnyMorganz/luau-lsp/1.70.1/scripts/globalTypes.d.luau
```
(в ссылке — версия luau-lsp из `rokit.toml`).

## Автодополнение (luau-lsp)
```bash
rojo sourcemap default.project.json -o sourcemap.json
```
```bash
lune setup
```
Первая команда даёт luau-lsp карту Roblox-инстансов, вторая — типы модулей Lune (алиас `@lune` в `.luaurc`).

## Структура
```
src/shared   чистая логика + Config + типы (тестируется в Lune)
src/server   серверные скрипты
src/client   клиент: рендер, UI, ввод
maps/        упакованные карты
tools/       Lune-скрипты (генерация карт)
tests/       Lune-тесты (*.spec.luau)
docs/        GDD, список арта, баланс, changelog
types/       определения Roblox для luau-lsp
roblox.yml   определения Roblox для selene
```
