# Перед публикацией

Всё, что делается руками в Creator Hub и Studio (кодом это сделать нельзя). Порядок — сверху вниз; каждый пункт
делается один раз. Проверка после публикации — `docs/STUDIO_CHECK.md` и F4 «Самопроверка».

## 1. Настройки игры

Studio → **File → Experience Settings** (или Creator Hub → игра → Configure):

| Где | Что включить | Зачем |
|---|---|---|
| Security → **Allow Mesh / Image APIs** | вкл. | карта и мини-карта рисуются в `EditableImage`; без этого вместо карты — сообщение об ошибке |
| Security → **Enable Studio Access to API Services** | вкл. | DataStore в Studio: профиль, покупки, таблицы лидеров (без этого в Studio — профиль на сессию) |
| Monetization / Avatar | ничего | персонажи выключены (`Players.CharacterAutoLoads = false`), игра 2D |
| Places → Server Size (Max Players) | 60 | больше держав в матче не бывает (`Config.Match.MaxPlayers`) |

DataStore создаются сами при первой записи, руками ничего заводить не нужно. Имена (менять только вместе с кодом):
`FrontirProfile_v1` — профили (`Config.Profile.StoreName`), `FrontirWeeklyWins_<неделя>` и `FrontirDuelElo` —
таблицы лидеров (`Config.Leaders`).

## 2. Товары: геймпассы и продукты разработчика

Creator Hub → игра → **Monetization**. Цены — из `Config.Shop` (Robux). После создания скопируйте id товара
и впишите в поле `id` той же строки `src/shared/Config.luau`. Пока `id = 0` — товар не продаётся, кнопка пишет
«Скоро».

**Passes** (геймпассы) → `Config.Shop.Passes.<Ключ>.id`:

| Ключ | Название | Цена |
|---|---|---|
| `HQ` | Штаб | 399 |
| `Intel` | Разведуправление | 249 |
| `Vip` | VIP | 299 |
| `AllCommanders` | Все генералы | 199 |

**Developer Products** → `Config.Shop.Boosts.<Ключ>.id` (бусты и платные части):

| Ключ | Название | Цена |
|---|---|---|
| `Mobilize` | Мобилизация | 49 |
| `Loan` | Военный заём | 39 |
| `Research` | Срочное исследование | 29 |

| `Airstrike` | Авиаудар | 45 |

**Developer Products** → `Config.Shop.Packs.<Ключ>.id` (наборы):

| Ключ | Название | Цена |

Значок товара — любой 512×512 (пока нет арта — можно без значка). Описание товара — короткое, как в магазине игры
(`Strings`, ключи `shop.*`).

## 3. Звуки и музыка

Roblox играет только загруженные звуки. Файлы готовы: `assets/audio/sfx/*.wav` (17 звуков) и
`assets/audio/music/*.wav` (3 мелодии: Lobby, Calm, Finale); пересоздать — `lune run tools/sfx_gen`.
Два способа (подробно — README «Звуки и музыка»):

1. **Через Config:** Creator Hub → Creations → **Audio → Import** (если WAV не примут — сконвертировать в OGG/MP3).
   Дождаться модерации, скопировать id и вписать как `"rbxassetid://123456"` в `Config.Sounds.<Имя>.id`
   или `Config.Music.<Имя>.id`.
2. **Без кода:** в Studio создать папку `SoundService/FrontirAudio` и положить туда `Sound` с именем звука
   (`Click`, `Siren`, `Calm`…). Такой `Sound` важнее id из Config.

Проверка — F4 «Звуки по очереди» и «Музыка: следующая».

## 4. Арт — по приоритету

Сейчас всё рисуется программно, игра без арта работает. Полный список размеров — `docs/ART_LIST.md`. Что заменить
первым (чаще всего на экране и в превью игры):

1. **Значок игры 512×512 и 2–3 превью-кадра 1920×1080** (Creator Hub → Places → Thumbnails) — без них игру
   не находят. Кадры — из Studio (карта «Европа», идёт война, видны фронты и самолёты).
2. **Иконки ресурсов и найма 8×8 / 16×16:** деньги, нефть, пехота, танки, артиллерия, ПВО.
3. **Юниты на фронте 8×6** (пехота, танки, артиллерия, ПВО) и **самолёты / корабли** — их видно весь матч.
4. **Значки столицы и города 16×16**, здания на карте 7×7.
5. **Эффекты боя** (вспышки, разрывы, дым) и падение самолёта.
6. **Пиксельный bitmap-шрифт с кириллицей** (сейчас `Config.Render.UiFont`, превью — `tools/font_preview`).
7. Иконки меню и окон (война, мир, порт, аэродром, генералы, технологии).

Все спрайты — только цвета из `docs/palette.md`, `ResampleMode = Pixelated`.

## 5. Возрастной рейтинг (Experience Questionnaire)

Creator Hub → игра → **Audience → Questionnaire** (без анкеты игру видят не все). Отвечать по-честному:

- **Насилие:** есть — бои стратегической карты (пиксельные юниты, взрывы), без крови и без людей крупным планом.
- **Кровь, страх, грубые шутки, алкоголь, азарт на реальные деньги:** нет.
- **Платные случайные награды:** **да** — «Ящик снабжения» и «5 ящиков» продаются за Robux (см. п. 6).
- **Общение:** стандартный чат Roblox; в игре — «пинги» на карте и готовые фразы Совета (без своего текста).
- **Реальные страны и политика:** нет — державы вымышленные, карты — только рельеф.

После анкеты рейтинг ставит Roblox; если он выше ожидаемого — смотреть, какой ответ его поднял.

## 6. Ящики и правила Roblox о платных случайных наградах

Сверка (что уже сделано в коде):

| Правило | Как в игре |
|---|---|
| Шансы каждой награды видны **до** покупки | окно магазина, раздел «Ящики снабжения»: проценты из `Config.Crates.Table` (`Profile.crateOdds`) |
| Гарантия / предсказуемость | не позже `Config.Crates.Pity`-го ящика подряд — джекпот; счётчик «до гарантии» в окне |
| Страны, где платные случайные награды запрещены | сервер при входе спрашивает `PolicyService:GetPolicyInfoForPlayerAsync` → `ArePaidRandomItemsRestricted` (не ответил — считаем «запрещено»). Тогда наборы ящиков не продаются (вместо кнопки — «Недоступно в вашем регионе») |
| **Косвенные** покупки тоже считаются | там же ящики из «Пропуска сезона» (премиум-ступени) и «Предложения недели» заменяются фиксированной наградой `Config.Crates.Restricted` (300 медалей + 1 жетон за ящик); ящик, всё же купленный (Robux списаны), — тоже замена |
| Бесплатные ящики | ежедневная награда и бесплатные ступени пропуска — ящики остаются (не за Robux) |
| Нельзя продавать ящик дороже честной цены, обманывать таймерами | ящики не в «ограниченное время», таймеров нет; «Предложение недели» меняется по настоящему календарю (`Shop.weekLeft`) |

Проверить после публикации: зайти с аккаунта из страны с ограничением (или временно заменить в
`ShopService.loadPasses` ответ на `ArePaidRandomItemsRestricted = true` в Studio) — кнопки «Ящик снабжения» и «5 ящиков»
скрыты, в «Предложении недели» вместо ящиков — медали и жетоны.

## 7. Последний шаг

1. `lune run tests`, StyLua, Selene, luau-lsp — зелёные (README «Тесты и проверки»).
2. Studio → **File → Publish to Roblox**, Experience → **Public**.
3. Сыграть один матч в опубликованной игре и пройти `docs/STUDIO_CHECK.md` (F4 «Самопроверка» → PASS).
