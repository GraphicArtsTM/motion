# MAXWAY — рилс (1080×1920, 35 с, 60 fps)

Монтаж для Instagram Reels из трёх кадров: реакция автора → монитор с After Effects → сам
моушн-ролик Maxway «KLABJON 1+1» на весь экран. Склейки спрятаны в движение камеры.
Звук: синтезированная музыка во вступлении, с 6-й секунды — оригинальная дорожка ролика.

Готовые видео в высоком качестве (H.264, CRF 17, 60 fps, звук −14 LUFS) лежат в `out/`:

| Файл | Заголовок |
|---|---|
| `out/MAXWAY_posmotrite.mp4` | MAXWAY, ПОСМОТРИТЕ, ЧТО Я СДЕЛАЛ! |
| `out/MAXWAY_uz.mp4` | MAXWAY, SIZ BUNI KO‘RDINGIZMI? |

## Рендер на своём ПК в один клик (Windows)

1. На GitHub: **Code → Download ZIP**, распаковать (нужна вся папка репозитория — шрифты лежат в `video/fonts`).
2. Дважды кликнуть `maxway-reel\RENDER.bat`.

Батник сам: ставит Python 3.12 (если его нет), скачивает ffmpeg с фильтром zscale в `tools\`,
ставит библиотеки в `.venv\`, скачивает исходники с Google Drive в `src\` и рендерит три видео
в `out\`, затем открывает эту папку. Повторный запуск ничего не скачивает заново.
Одну версию: `RENDER.bat --titles uz`; свой текст: `python render_all.py --titles "ТВОЙ ТЕКСТ"`.

## Идея

Ролик Maxway начинается со слов «КУПИ → ОДИН → ПОЛУЧИ → ДВА», а на мониторе в After Effects
как раз проигрывается «КУПИ → ОДИН». Камера влетает в окно композиции, и «ПОЛУЧИ» уже
на весь экран — смысл фразы продолжается сквозь склейку.

| Время | Что в кадре | Монтаж / VFX | Музыка |
|---|---|---|---|
| 0–3 с | Селфи: думает → смотрит в камеру → «смотри туда» | 3D-заголовок «MAXWAY, / ПОСМОТРИТЕ, ЧТО Я СДЕЛАЛ!» падает по буквам, плашка по словам; панч-зум на жест | удар на заголовке, приглушённый грув «через стену» |
| 3 с | Вип-пан на ПК | склейка в смазе движения: оба дубля уходят вправо, световой прорыв | свуш + удар |
| 3–6 с | Монитор с After Effects | трекинг окна композиции, жёлтые HUD-уголки, плашка «сделано в After Effects»; время монитора подогнано так, что «КУПИ» и «ОДИН» падают ровно в доли | фильтр открывается, стэбы на «КУПИ / ОДИН», раскатка малого |
| 5,25–6 с | Влёт в экран | гомография по 4 углам окна → весь кадр, окно подменяется чистым роликом, честный моушн-блюр, вспышка | свуш, райзер |
| 6–35 с | Ролик Maxway целиком, без рамки и заголовка, в безопасной зоне: 90 % кадра, поля дорисованы продолжением фона (Instagram на высоких iPhone срезает ~50 px по бокам) | на «ПОЛУЧИ», «ДВА» и дропе «1+1» — тряска, хроматическая аберрация, вспышки, ударная волна; дальше ролик идёт чистым | оригинальная дорожка ролика |

Режим «3D-карточка» (ролик в парящей рамке с сэндвичами вокруг) остался: `edit.py --layout card`.

## Цвет и безопасные зоны

- Цветокоррекция версии 1: HDR (HLG) с iPhone → SDR тонмаппингом Hable, мягкая S-кривая,
  насыщенность ×1,1, лёгкое тепло, виньетка (`grade()` в `edit.py`).
- Заголовок ниже верхних 14 % кадра (≈270 px — надпись Reels и камера), не заходит в колонку
  кнопок справа и в нижнюю зону подписи.

## Сборка

Нужны Python 3 (numpy, opencv-python-headless, pillow) и ffmpeg с zscale.

```bash
./build.sh            # = python3 render_all.py; исходники скачаются в src/ сами
python3 edit.py --src work/sdr --track track_6298.json --stills 2.3,5.7,9.5   # стоп-кадры
```

- `render_all.py` — весь конвейер: исходники → HDR→SDR → трекинг → музыка → монтаж → 3 видео
- `RENDER.bat` — то же на Windows в один клик, с установкой Python, ffmpeg и библиотек
- `track_screen.py` — трекинг окна композиции (сиреневый прямоугольник) по каждому кадру
- `edit.py` — весь монтаж, кадр детерминированно рисует `Edit.render(T)`
- `assets.py` — 3D-текст с экструзией, плашки, искры, вырезка сэндвичей из финальной сцены ролика
- `music.py` — саундтрек, `timeline.py` — общая сетка событий для картинки и звука

Видео с iPhone записано в HDR (HLG): `build.sh` переводит его в SDR с тонмаппингом,
иначе в Instagram цвета выгорают.
