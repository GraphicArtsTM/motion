# MAXWAY, посмотрите, что я сделал! — рилс (1080×1920, 35 с, 60 fps)

Монтаж для Instagram Reels из трёх кадров: реакция автора → монитор с After Effects → сам
моушн-ролик Maxway «KLABJON 1+1». Склейки спрятаны в движение камеры, музыка синтезирована
и стоит на сетке самого ролика (120 BPM).

Готовое видео: `out/maxway-reel-1080x1920.mp4`
(вариант с оригинальным звуком ролика после 6-й секунды — `out/maxway-reel-1080x1920_original-audio.mp4`).

## Идея

Ролик Maxway начинается со слов «КУПИ → ОДИН → ПОЛУЧИ → ДВА», а на мониторе в After Effects
как раз проигрывается «КУПИ → ОДИН». Камера влетает в окно композиции, и «ПОЛУЧИ» уже
на весь экран — смысл фразы продолжается сквозь склейку.

| Время | Что в кадре | Монтаж / VFX | Музыка |
|---|---|---|---|
| 0–3 с | Селфи: думает → смотрит в камеру → «смотри туда» | 3D-заголовок «MAXWAY, / ПОСМОТРИТЕ, ЧТО Я СДЕЛАЛ!» падает по буквам, плашка по словам; панч-зум на жест | удар на заголовке, приглушённый грув «через стену» |
| 3 с | Вип-пан на ПК | склейка в смазе движения: оба дубля уходят вправо, световой прорыв | свуш + удар |
| 3–6 с | Монитор с After Effects | трекинг окна композиции, жёлтые HUD-уголки, плашка «сделано в After Effects»; время монитора подогнано так, что «КУПИ» и «ОДИН» падают ровно в доли | фильтр открывается, стэбы на «КУПИ / ОДИН», раскатка малого |
| 5,25–6 с | Влёт в экран | гомография по 4 углам окна → весь кадр, окно подменяется чистым роликом, честный моушн-блюр, вспышка | свуш, райзер |
| 6–8,75 с | «ПОЛУЧИ», «ДВА», «1+1» на весь экран | тряска, хроматическая аберрация, вспышки, ударная волна на дропе | вакуум → **дроп на «1+1»** |
| 8,75–35 с | Ролик как парящая 3D-карточка | перспектива и покачивание, панч на каждой смене сцены, стеклянный блик, фон из размытого ролика, сэндвичи и плашки «1+1» летают вокруг с глубиной резкости | хаус-бит, дутар, дойра; удары на сменах сцен, «зачёркивание» на «клаб-сэндвич?», конфетти, галочка, тиканье маршрута, финальный удар на логотипе |

## Сборка

Нужны Python 3 (numpy, opencv-python-headless, pillow) и ffmpeg с zscale.

```bash
# исходники в src/: IMG_6290.MOV, IMG_6298.MOV, k3.mp4
./build.sh
python3 edit.py --src work/sdr --track track_6298.json --stills 2.3,5.7,9.5   # стоп-кадры
```

- `track_screen.py` — трекинг окна композиции (сиреневый прямоугольник) по каждому кадру
- `edit.py` — весь монтаж, кадр детерминированно рисует `Edit.render(T)`
- `assets.py` — 3D-текст с экструзией, плашки, искры, вырезка сэндвичей из финальной сцены ролика
- `music.py` — саундтрек, `timeline.py` — общая сетка событий для картинки и звука

Видео с iPhone записано в HDR (HLG): `build.sh` переводит его в SDR с тонмаппингом,
иначе в Instagram цвета выгорают.
