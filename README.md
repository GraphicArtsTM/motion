# Паук Новограда — студия сериала (GraphicArts Animation)

Мультсериал в духе комиксов про человека-паука, полностью собранный на **Three.js**: 3D-город, персонажи,
лаборатория, мост, дождь, молнии, паутина — всё процедурное и рисуется кадр за кадром. Озвучка — живой голос
автора, нарезанный и синхронизированный автоматически; музыка и звуки синтезированы и сведены под картинку.

| Серия | Что готово |
|---|---|
| **1. «Укус молнии»** — `episodes/e01` | готовая серия, 3:46 + заставка студии |
| **2. «Личная жизнь»** — `episodes/e02` | готовая серия ≈ 4:01 + заставка: лицей, Диёр, Маржон (Эм-Джей), драка с Азимом, тизер злодея ODILMAN. Голоса — ИИ (свою запись можно подложить по `VOICEOVER.md`) |
| 3–10 | план в [`SERIES_BIBLE.md`](SERIES_BIBLE.md) |

- **Библия сериала** (мир, правила сил, персонажи, кто такая Тень, план сезона): [`SERIES_BIBLE.md`](SERIES_BIBLE.md)
- **Инструкция для новой сессии ИИ / разработчика** (как всё устроено, как делать серии): [`CLAUDE.md`](CLAUDE.md)
- Сценарии: [`episodes/e01/STORY.md`](episodes/e01/STORY.md), [`episodes/e02/STORY.md`](episodes/e02/STORY.md)
- Озвучка: [`episodes/e02/VOICEOVER.md`](episodes/e02/VOICEOVER.md)

## Собрать видео в один клик

| Система | Что запустить |
|---|---|
| **Windows** | двойной щелчок по **`RENDER_WINDOWS.bat`** → ввести номер серии (1, 2…) → Enter |
| **macOS / Linux** | `./render_mac_linux.sh` (или `./render_mac_linux.sh e02`) |

Скрипт сам поставит Node.js (если его нет), библиотеки (Playwright + ffmpeg) и браузер для рендера, отрисует
серию на видеокарте и положит видео в `out/PAUK_NOVOGRADA_S01E0N_1920x1080.mp4`.
Python и синтезаторы речи для этого **не нужны** — готовый звук лежит в `episodes/<серия>/assets/`.

Параметры (после имени скрипта или `node make-video.mjs …`):

```
--ep e02              какая серия
--fps 24              частота кадров (по умолчанию 30)
--jobs 2              число параллельных потоков рендера
--fast                быстрый режим (без сглаживания, теней, размытия) — для проверки
--from 100 --to 120   только кусок (секунды ролика)
```

Посмотреть серию в браузере со звуком: `node preview.mjs e02` (пробел — пауза, ←/→ — перемотка).

## Озвучить серию своим голосом

1. Откройте `episodes/e02/VOICEOVER.md` — там все реплики по порядку, с подсказками и максимальной длиной.
2. Запишите **все реплики подряд одним файлом** (диктофон телефона подойдёт), между репликами — пауза 1–2 с.
3. Пришлите файл (или положите в `episodes/e02/audio/voice_src/`) — дальше `tools/audio.sh e02` нарежет запись,
   обработает голоса (телефон, эхо, рация, шлем) и сведёт звук с липсинком.

## Как устроено

```
engine/      общий движок: город, персонажи, интерьеры, эффекты, 2D-слой, постобработка, звук
episodes/    серии: e01, e02, _template (заготовка новой серии)
tools/       new-episode.mjs, audio.sh, voiceover.py, pack.py
```
Подробно — в [`CLAUDE.md`](CLAUDE.md).

## Новая серия

```
node tools/new-episode.mjs 3 "Линия 0"     # episodes/e03 из шаблона, сразу рендерится
tools/audio.sh e03                          # голоса и звук
node render.mjs --ep e03 --story --stills 5,20,35   # проверочные кадры
```

## Весь проект одним архивом

`python3 tools/pack.py` → `out/PAUK_NOVOGRADA_STUDIO.zip`. Этот архив можно отправить в новую сессию:
в нём движок, все серии, звук, библия, инструкции — всё нужное для следующих серий.
