# M Cosmetic — Reels «старое видео / моё видео» (1080×1920, 29 с, 60 fps)

Ролик для Instagram Reels с отметкой бренда **@mcosmetic_uz**: в одной руке — старый ролик компании,
в другой — мой, и мой улетает на весь экран. Надписи на узбекском (латиница).

Готовое видео: `out/mcosmetic-reels-uz-1080x1920.mp4`
(первая, русская версия — `out/mcosmetic-reels-1080x1920.mp4`).

## Сценарий (120 BPM — темп нового видео, все события на долях)

| Время | Что происходит |
|---|---|
| 0–1,5 с | Хук: плашка **@mcosmetic_uz**, 3D-заголовок «SIZ BUNI KO‘RDINGIZMI?» влетает по словам на долях, из него разлетаются 3D-цветы бренда |
| 1,5–4 с | Над левой ладонью включается голограмма (кольцо-излучатель, луч, искры) со **старым** видео; подпись «1 · ESKISI» |
| 4–5 с | Штамп «✕ G‘ALATI», экран глючит (RGB-расслоение, срезы), обесцвечивается |
| 5 с | Экран разбивается на 3D-осколки, ударная волна |
| 5,5–6 с | Вайп с моушн-блюром к правой руке (дубль ускорен в 4,8 раза) |
| 6–8 с | Розовая голограмма с **моим** видео (оно стартует здесь же, со звуком «из голограммы»), подпись «2 · YANGISI ✓», золотая галочка, анаморфный блик и цветы |
| 8–9 с | Замах, экран отрывается от ладони и вылетает в камеру; удар на сильной доле |
| 9–22,4 с | Моё видео на весь экран (удар, ударная волна, блик, взрыв цветов), первые секунды — плашка «YANGISI ✓», со своим звуком до конца |
| 22,4–25 с | Видео сжимается в карточку «2», рядом прилетает «1» (✕). Подписи «ESKISI» / «YANGISI», вопрос «QAYSI BIRI ZO‘R? 1 yoki 2? Izohlarda yozing» |
| 25–27 с | Карточка «2» выходит вперёд, «1» уходит в тень; дождь цветов, музыка раскрывается |
| 27–29 с | Последний удар на сильной доле, звенящий хвост и плавное затемнение |

Голограммы держатся на ладонях по трекингу MediaPipe Hand Landmarker (`track_hands.py` → `hands.js`):
центр ладони, размер кисти и верх пальцев для каждого кадра дубля.

## Звук

`sound.py` строит саундтрек на основе музыки нового видео, поэтому всё синхронно:
в начале — тот же трек приглушённо (лоу-пасс) + синтезированные барабаны на той же сетке, заикание и
остановка плёнки на «BU EMAS», звон стекла; с 6,378 с звучит само новое видео — узкой полосой, как из
голограммы, и раскрывается в полный звук к удару на 9 с. Громкость — двухпроходный loudnorm точно в −14 LUFS.

## Сборка

Нужны Node.js с Playwright (Chromium), Python 3 с numpy и ffmpeg (с zscale).
Исходники — в `src/`: `IMG_6384.MOV`, `old video.mp4`, `new video.mp4`.

```bash
./build.sh                                  # кадры → музыка → рендер → out/mcosmetic-reels-uz-1080x1920.mp4
node render.mjs --stills 2.6,4.2,7.8,24.6   # стоп-кадры для проверки в out/stills/
```

Отметка бренда — константа `HANDLE` в начале `motion.js`, остальные надписи — в `index.html`.
Предпросмотр в браузере: `index.html` (по кругу) или `index.html?t=8.5` (стоп-кадр).
