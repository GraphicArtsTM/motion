# «Farqi nimada?» — reels 1080×1920 (9:16)

Информативный мультфильм для Instagram Reels на узбекском: четыре пары терминов, которые часто путают,
и разница между ними. Озвучка нейроголосом, динамичная музыка, крупные субтитры, рисованные мультсцены
с анимированными персонажами.

Готовое видео: `out/farq-reels-1080x1920.mp4` (~115 с, 30 fps, H.264 + AAC, −14 LUFS).

## Структура

| Сцена | Что происходит |
|---|---|
| Интро | Вечерний город, люди путаются в словах: над головами «?», пузыри «Kommunizm? Respublika?…», удар «2 SO‘Z / 1 FARQ» |
| Пара ×4: столкновение | Шторка в цветах пары, фон-комикс (лучи, растр, линии скорости), два слова сталкиваются, «VS», вспышка, тряска |
| Пара ×4: две мультсцены | Полноэкранная рисованная сцена на каждый термин, камера двигается и «бьёт» на ключевых словах; баннер термина, стикер ключевого слова, субтитры по 2–3 слова |
| Пара ×4: итог | Сцена уходит в размытый фон, «Qisqa farq»: тезисы обоих терминов и знак ≠ |
| Финал | «Eslab qoling», «Saqlang / Ulashing / Obuna bo‘ling» на этих словах, персонажи машут |

Мультсцены (`scenes.js`), события привязаны к моментам ключевых слов в озвучке:

- **Kommunizm** — пирамида классов: рабочие держат клерков, наверху богач в цилиндре. На «sinfsiz» пирамида рушится,
  все приземляются в один ряд и берутся за руки; на «xususiy mulk bo‘lmagan» с завода слетает замок, вывеска XUSUSIY → UMUMIY;
  на «maqsad» встаёт солнце.
- **Sotsializm** — общий склад OMBOR открывается, ресурсы летят в школу, больницу и людям, загораются окна, сердечки;
  на «boshqarishga» появляется управляющий с планшетом и шестерня.
- **Demokratiya** — очередь избирателей опускает бюллетени в прозрачную урну, народ ликует, на ступенях парламента
  появляются избранные представители.
- **Respublika** — король на троне передаёт корону принцу («MEROS»), её перечёркивает красный крест и корона раскалывается;
  на площади голосуют, кандидат получает ленту, конфетти, встаёт здание парламента.
- **Millatchilik** — горы и восточный портал с куполом, люди в чапанах и тюбетейках, дутар; появляются лаган, нон, атлас;
  флаг поднимается и разворачивается; купол-щит накрывает город, грозовые тучи отскакивают.
- **Shovinizm** — один поднимается на пьедестал, кричит в мегафон «MEN USTUNMAN!», остальные уменьшаются и грустнеют,
  стрелки вниз, в конце знак STOP.
- **Kapitalizm** — частный завод с вывеской XUSUSIY, хозяин с ключом и монетами; рынок из двух лавок, цены падают по очереди,
  продавцы зазывают, график гонки конкурентов.
- **Sotsializm (2)** — государственное здание с шестернёй, школа и больница, бригада вместе катит огромную шестерню,
  государство раздаёт ящики людям.

Персонажи — марионетки (`art.js`): походка, руки на двух суставах, моргание, мимика (улыбка, крик, грусть, удивление),
речь губами, одежда (костюм, комбинезон, платье, чапан, королевская мантия), головные уборы (цилиндр, каска, корона, тюбетейка, платок).

## Голос

`tts.py` выбирает первый доступный движок:

1. **edge** — нейроголос Microsoft `uz-UZ-SardorNeural`, настоящий узбекский. Нужен доступ к `speech.platform.bing.com`.
2. **piper** — офлайн-нейроголос Piper `tr_TR-fettah-medium` (VITS, через sherpa-onnx; датасет под CC0, можно в коммерческих целях).
   Модель сама скачивается из релизов sherpa-onnx на GitHub в `models/`. Узбекская латиница переводится в турецкую орфографию
   с близким произношением. Выбран среди 5 вариантов по разборчивости: узбекскую речь распознавал Whisper
   (голос `tr_TR-dfki` разборчив так же, но его датасет только для некоммерческого использования).
3. **mbrola** — запасной: espeak-ng + MBROLA tr1.

Текущее видео озвучено движком **piper**: сервис Microsoft закрыт сетевой политикой окружения, где собиралось видео.
Чтобы переозвучить настоящим узбекским нейроголосом, на машине с интернетом: `pip install edge-tts && ./build.sh --engine edge`.
Тайминги, анимация, субтитры и музыка перестроятся сами.

## Текст

Весь текст — в `script.json`. Исправления относительно исходника:

- Kommunizm: «ishlab chiqarish vositalari xususiy mulk bo‘lmagan» вместо «xususiy ishlab chiqarish mulki bo‘lmagan».
- Respublika: «davlat boshlig‘i monarx kabi meros orqali emas, saylov yo‘li bilan hokimiyatga keladigan davlat shakli».
- Kapitalizm: определение оформлено одним предложением «… muhim rol o‘ynaydigan iqtisodiy tizim».
- Sotsializm (4): «ijtimoiy manfaatlarga hamda resurslarni …» — убрана двусмысленность.
- Пункту 4 добавлен вопрос «Kapitalizm va sotsializm farqi nimada?».

## Сборка

```bash
pip install numpy sherpa-onnx        # + Node.js с Playwright (Chromium) и ffmpeg
./build.sh                           # голос → музыка → кадры в 4 потока → out/farq-reels-1080x1920.mp4
node render.mjs --stills 12,27.5     # стоп-кадры в out/stills/
```

- `tts.py` — озвучка, раскладка по сетке 120 BPM, время каждого слова и ключевых слов → `timeline.js`, `out/voice.wav`.
- `music.py` — трек на numpy, энергия по сценам, звуки на событиях кадра, сайдчейн под голос → `out/mix.wav`.
- `index.html` + `motion.js` — монтаж, титры, переходы; `scenes.js` — мультсцены; `art.js` — персонажи, здания, предметы.
  Предпросмотр: `index.html` (по кругу) или `index.html?t=20` (стоп-кадр).
- `render.mjs` — покадровый рендер через Chromium в ffmpeg.

Шрифты Unbounded и Rubik (`../video/fonts`) — Google Fonts, SIL OFL. Голос Piper tr_TR-fettah — датасет NabuCasa, CC0.
