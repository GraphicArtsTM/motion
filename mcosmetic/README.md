# M Cosmetic — «Mega chegirma» (1080×1920, 9:16, 16 с, 60 fps)

Рекламный моушн-ролик для Reels/Stories/TikTok по акции с постера: **каждый месяц 25–26-го числа — скидки до −50%
на ограниченный ассортимент**. Стиль взят с постера и сайта mcosmetic.uz: лучи розово-сиреневого «санбёрста»,
скруглённые карточки со сдвинутой тёмной подложкой, четырёхлепестковые цветы, фирменный пурпурный `#C0288B`,
шрифт Montserrat (с сайта), логотип и 3D-рендеры товаров из каталога сайта.

Готовое видео: `out/mcosmetic-mega-chegirma-1080x1920.mp4`.

## Сценарий (синхронно с голосом)

Голос (узбекский) стоит с 1,0 с. Музыка 120 BPM, сетка подогнана так, что ключевые слова попадают в доли.

| Время | Голос | Что в кадре |
|---|---|---|
| 0–0,6 с | — | Лучи раскрываются, падает плашка логотипа |
| 0,6–1,6 с | «Har oyning…» | Удар: карточка **MEGA CHEGIRMA**, буквы влетают, вспышка, цветы |
| 1,6–3,4 с | «…25- va 26-sanalarida» | Листки календаря «25» и «26» перелистываются в ритм |
| 3,4–4,1 с | | Календари сжимаются в блок **HAR 25-26 KUNLARI / КАЖДОГО 25-26ГО ЧИСЛА** (композиция постера) |
| 4,1–6,8 с | «M Cosmetic — sizga maxsus narxlar…» | Круговое раскрытие пурпурного фона, сборка логотипа, товары влетают, слова SIZGA / MAXSUS / NARXLAR |
| 6,8–8,1 с | «Cheklangan assortimentga…» | Карусель товаров со стикерами «%», нарастание, всасывание в центр |
| 8,1–10,1 с | «…50 foizgacha chegirmalar» | Дроп: **ДО −50% GACHA** со счётчиком, конфетти, товары по орбите, CHEGIRMALAR! |
| 10,1–12,6 с | «Taklif faqat mahsulot mavjud boʻlganda amalda» | Условия «*cheklangan assortiment uchun», караоке-подсветка слов, полка с товарами |
| 12,6–16 с | — | Финал: логотип, MEGA CHEGIRMA, даты, стикер −50%, кнопка mcosmetic.uz, юридическая строка с постера |

## Звук

- `assets/voice-original.mp3` — присланная запись. В ней была своя подложка (обрывалась на 9-й секунде),
  поэтому голос выделен нейросетью Demucs (htdemucs, two-stems) → `assets/voice.wav`.
- `music.py` синтезирует трек на numpy без сэмплов: поп-хаус в фа-диез миноре (F#m–D–A–E), бочка, клэп, хэты,
  шейкер, бас, плаки, суперсо, хук на дропе, финальное разрешение в ля мажор. Эффекты привязаны к кадру:
  удары надписей, шорох календаря, «чпок» товаров и стикеров, блики, всасывание перед дропом, касса и монеты на −50%,
  щелчок по кнопке. Музыка приглушается под голос, итог нормализуется до −14 LUFS.

## Сборка

Нужны Node.js с Playwright (Chromium), Python 3 с numpy и ffmpeg.

```bash
./build.sh                                   # саундтрек → кадры → out/mcosmetic-mega-chegirma-1080x1920.mp4
node render.mjs --stills 3.8,8.6,15.5        # стоп-кадры в out/stills/
```

Предпросмотр: открыть `index.html` (проигрывается по кругу) или `index.html?t=8.6` (стоп-кадр).
Всё движение — в `motion.js`, функция `renderAt(t)`.

Повторное выделение голоса (не входит в build.sh):

```bash
pip install demucs && python3 -m demucs --two-stems=vocals -n htdemucs -o sep voice.wav
```
