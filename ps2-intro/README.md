# PlayStation 2 — современное интро (16:9)

Две версии ролика, обе в 1920×1080 (или 4K), 60 fps, с оригинальной музыкой и новым саунд-дизайном:

| Версия | Длина | Что это |
|---|---|---|
| **Director's Cut** | 26 с | Моя авторская версия. Пролог: в темноте зажигается точка, по зеркальному полу разбегаются четыре цветных огня и волна. Камера стартует у самого пола и поднимается краном, пока вокруг вырастают светящиеся башни. Нырок в центр, гиперпространство, огни закручиваются в спираль и сталкиваются. Логотип собирается из 11 000 частиц и превращается в объёмный металлический, камера облетает его, огни кружат вокруг и отражаются в полу. |
| **Remake** | 20 с | Бережный ремейк оригинала: тот же тайминг и композиция кадр в кадр с оригинальной дорожкой, но современная графика — объёмный туман, свечение, лучи, хвосты огней, плавная камера, вспышки, ударные кольца на логотипе. |

## Как отрендерить (один клик)

**Windows:** дважды кликнуть `RENDER_WINDOWS.bat`.

Скрипт сам:
1. скачает портативный Node.js, если его нет (в папку `tools/`, без установки в систему);
2. установит библиотеки (`playwright`, `ffmpeg-static`) — один раз;
3. отрендерит обе версии через ваш Chrome или Edge (на видеокарте) и сведёт видео со звуком;
4. откроет папку `out/` с готовыми файлами:
   - `out/PS2_Intro_DirectorsCut_1080p60.mp4`
   - `out/PS2_Intro_Remake_1080p60.mp4`

Другие варианты:
- `RENDER_4K_WINDOWS.bat` — то же самое в 3840×2160;
- `PREVIEW_WINDOWS.bat` — открыть живое превью в браузере (клик по странице включает звук; адрес `?v=remake` — ремейк);
- macOS: `render-mac.command`, Linux: `render-linux.sh`.

Время рендера на обычном ПК с видеокартой — несколько минут на версию. Если в консоли написано
«рендер идёт на процессоре», обновите драйвер видеокарты или установите Google Chrome. Тогда будет быстрее.

### Параметры (для командной строки)

```bash
node render-all.mjs                    # обе версии, 1080p60
node render-all.mjs --only pro         # только Director's Cut
node render-all.mjs --only remake      # только Remake
node render-all.mjs --scale 2          # 4K
node render-all.mjs --fps 30           # 30 кадров/с, вдвое быстрее
node render-all.mjs --fast             # кадры в JPEG вместо PNG: быстрее, чуть хуже градиенты
node render-all.mjs --headed           # рендер в видимом окне браузера (если фоновый не берёт видеокарту)
node render.mjs --version pro --stills 4.2,17.5   # стоп-кадры в out/stills/
```

## Звук

- `audio/original.wav` — оригинальная дорожка из присланного видео, без изменений;
- `audio/soundtrack.wav` — Remake: оригинал + звуковые эффекты;
- `audio/soundtrack_pro.wav` — Director's Cut: оригинал (вступает на 2,5 с) + пролог, пэды, удары, райзеры, искры, «защёлкивание» логотипа.

Все эффекты синтезированы с нуля в `sfx.py` (numpy, без сэмплов) и привязаны к событиям в кадре:
удары при росте башен, свисты пролёта огней, мерцание надписи, райзер и удар при нырке, ускоряющиеся спиральные
пролёты в гиперпространстве, «вдох» перед ударом логотипа, искры частиц, блики. Звон логотипа из оригинала
оставлен главным, эффекты сведены под него. Пересобрать звук после правок: `python sfx.py` (нужен numpy).

## Устройство

- `index.html` + `js/intro.js` — вся анимация на Three.js. Функция `renderAt(t)` детерминированно рисует кадр
  для момента `t`, поэтому рендер покадровый и не зависит от скорости компьютера. Тайминги — объект `T` в начале файла.
- Постобработка: bloom, объёмные лучи, хроматическая аберрация, виньетка, плёночное зерно, вспышки.
- `assets/ps2-logo.svg` — логотип, векторизован из кадра оригинального видео. В Director's Cut из него же строится 3D-модель.
- `render.mjs` — локальный сервер, браузер через Playwright, кадры отправляются в ffmpeg и сводятся со звуком.
- `lib/three/` — Three.js r170 (MIT), `fonts/` — Jost (SIL Open Font License).
