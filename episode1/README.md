# Паук Новограда — Серия 1 «Укус молнии»

Мультсериал в духе комиксов про человека-паука, полностью собранный на **Three.js**: 3D-город, персонажи,
лаборатория, мост, дождь, молнии и нити паутины — всё процедурное и рисуется кадр за кадром.
Музыка, звуковые эффекты и озвучка синтезируются офлайн и сводятся под картинку.

- Формат: **1920×1080 (16:9)**, 24 fps, 3:36, звук AAC стерео, −15 LUFS
- Готовое видео: `out/pauk-novograda-s01e01-1920x1080.mp4`
- Сценарий, персонажи и покадровая раскадровка: [`STORY.md`](STORY.md)

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html` | плеер: открывается в браузере, играет серию со звуком (пробел — пауза, ←/→ — перемотка) |
| `src/main.js` | рендерер, bloom, таймлайн, `renderAt(t)` — детерминированный кадр для момента `t` |
| `src/shots.js` | режиссура: 33 шота — камера, позы, эффекты, комикс-надписи |
| `src/rig.js` | персонажи из примитивов (иерархический риг, библиотека поз, мимика, липсинк), паучки «Арахна» |
| `src/city.js` | Новоград: небоскрёбы с процедурными окнами (инстансы + шейдер), мокрые улицы, река, мост, башня «Аркада», дождь, молнии, машины, автобус №42 |
| `src/interiors.js` | лаборатория, кухня деда, логово Тени |
| `src/fx.js`, `src/overlay.js` | нити паутины, искры, кольца «паучьего чутья»; субтитры, заставка, окно звонка, комикс-надписи |
| `timeline.json` | длительность и удары молний (общие для картинки и звука) |
| `audio/dialogue.json` | реплики с таймингом |
| `audio/voices.py` | озвучка: RHVoice (русские дикторы) и Piper (нейросетевой голос) |
| `audio/mix.py` | синтез музыки и эффектов на numpy, обработка голосов, сайдчейн под речь, липсинк |
| `render.mjs` | покадровый рендер через Playwright/Chromium → ffmpeg |

## Сборка

Нужны Node.js + Playwright (Chromium), Python 3 + numpy, ffmpeg, а для голосов — RHVoice и Piper:

```bash
sudo apt install rhvoice rhvoice-russian espeak-ng
pip install piper-tts numpy
# голос Piper ru-irinia-medium (из релиза rhasspy/piper v0.0.2) → /opt/voices/ru-irinia-medium.onnx
./build.sh                                   # голоса → звук → кадры в 2 потока (~1,5 ч) → итоговый mp4
node render.mjs --stills 41.5,110,169.2      # стоп-кадры в out/stills/ для проверки
```

Предпросмотр: `npx serve .` в папке `episode1` и открыть `http://localhost:3000/` (или `?t=108` — с нужной секунды).
