# Паук Новограда — Серия 1 «Укус молнии»

Мультсериал в духе комиксов про человека-паука, полностью собранный на **Three.js**: 3D-город, персонажи,
лаборатория, мост, дождь, молнии и нити паутины — всё процедурное и рисуется кадр за кадром.
Озвучка — живой голос автора (`audio/voice_src/golos_01.mp3`), нарезанный и синхронизированный автоматически;
музыка и звуковые эффекты синтезированы и сведены под картинку.

- Формат: **1920×1080 (16:9)**, 30 fps (или любой другой), 3:46, звук AAC стерео, −15 LUFS
- Сценарий, персонажи и раскадровка: [`STORY.md`](STORY.md) · тексты для озвучки: [`VOICEOVER.md`](VOICEOVER.md)

## Собрать видео в один клик

| Система | Что запустить |
|---|---|
| **Windows** | двойной щелчок по **`RENDER_WINDOWS.bat`** |
| **macOS / Linux** | `./render_mac_linux.sh` в терминале |

Скрипт сам поставит Node.js (если его нет), библиотеки (Playwright + ffmpeg) и браузер для рендера,
отрисует серию на видеокарте и положит готовый файл в `out/PAUK_NOVOGRADA_S01E01_1920x1080.mp4`.
Python, ffmpeg и синтезаторы речи для этого **не нужны** — готовый звук уже лежит в `assets/soundtrack.m4a`.

Параметры (можно дописать после имени скрипта или запускать `node make-video.mjs …`):

```
--fps 24          частота кадров (по умолчанию 30)
--jobs 2          число параллельных потоков рендера
--fast            быстрый режим без сглаживания — для проверки
--from 100 --to 120   отрендерить только кусок (секунды)
```

Посмотреть мультфильм прямо в браузере со звуком: `node preview.mjs` (пробел — пауза, ←/→ — перемотка).

## Как устроено

| Файл | Что делает |
|---|---|
| `src/main.js` | рендерер, bloom, карта времени (сюжет → экран), `renderAt(t)` — детерминированный кадр |
| `src/shots.js` | режиссура: 33 шота — камера, позы, эффекты, комикс-надписи |
| `src/rig.js` | персонажи: риг, IK рук, squash & stretch, вторичная анимация, кисти с пальцами, веки, рот «о/и/с», библиотека поз и жестов |
| `src/city.js`, `src/props.js` | Новоград: небоскрёбы (силуэты и ТВ в окнах, сглаживание вдали), мокрые улицы с неоном в лужах, мост, башня «Аркада», прохожие, светофоры, реклама, полиция |
| `src/interiors.js`, `src/dressing.js` | лаборатория (голограмма, пар, маячки), мост (вертолёт, дым, обломки), кухня (кот, часы, пар), логово Тени |
| `timeline.json` | молнии и растяжки сцен под живую озвучку |
| `audio/align_voice.py` | нарезка одной длинной записи на реплики (VAD + MFCC/DTW + динамическое программирование) |
| `audio/voices.py`, `audio/mix.py` | обработка голоса, синтез музыки и эффектов, сведение, липсинк |
| `make-video.mjs`, `render.mjs` | покадровый рендер в Chromium (на видеокарте) и сборка mp4 |

### Пересобрать звук (нужен Python)

```bash
pip install numpy numba
python3 audio/align_voice.py audio/voice_src/golos_01.mp3   # нарезка записи → audio/voice_user/
python3 audio/voices.py && python3 audio/mix.py             # обработка голосов, музыка, сведение
```

Если какая-то реплика нарезалась неточно, поправьте номера участков в `audio/voice_src/golos_01.map.json`.
