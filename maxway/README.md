# Maxway — KLABJON 1+1 (1080×1920, 9:16, 30 с, 60 fps)

Динамичный моушн-ролик для акции Maxway «1+1» на KLABJON L — альтернативу клаб-сэндвичу.
Стилистика — кинетическая типографика и UI-промо: слова на каждую долю с контурными эхо, удары камеры в такт,
наклейки с пружиной, шторки-переходы полосами, лучи, бегущие ленты, зерно. Цвета и элементы взяты из приложения
и баннера Maxway: фиолетовый `#7669AF` из логотипа, оранжевый и жёлтый баннера KLABJON, интерфейс приложения
(главная, карточка товара, «Добавить», корзина с подарком за 0 сум, «К оплате», карта и «Время доставки 40 мин»).

Готовое видео: `out/maxway-klabjon-1080x1920.mp4`.

## Сценарий (120 BPM, склейки на долях)

| Время | Сцена | Что происходит |
|---|---|---|
| 0–2 с | Хук | «КУПИ / ОДИН / ПОЛУЧИ / ДВА» — по слову на долю, контурные эхо разлетаются |
| 2–4 с | 1+1 | Жёлтая пилюля «1+1» с баннера, цифры падают по очереди, лучи, бегущие ленты |
| 4–8 с | Продукт | KLABJON (L) по буквам, сэндвич влетает, подписи ингредиентов, 385 г, ★ 4.0, «Новинка» |
| 8–10 с | Твист | «КЛАБ-СЭНДВИЧ?» зачёркивается маркером и падает → удар «KLABJON — альтернатива клаб-сэндвичу» |
| 10–14 с | Приложение | Телефон с главной Maxway, тап «Акция», тап «Добавить», товар летит в корзину, бейдж 1 → 2 |
| 14–18 с | Корзина | Шторка корзины, «KLABJON L в подарок»: 40 000 → 0 сум, конфетти, «К оплате 41 000 сум», заказ оформлен |
| 18–22 с | 1+1 | Сэндвич раздваивается, бант падает на второй, «ВТОРОЙ В ПОДАРОК», ключевой визуал с баннера |
| 22–25 с | Доставка | Карта, маршрут от Maxway до дома, «40 МИН», лента «*Акция действует только на доставку» |
| 25–30 с | Финал | Логотип maxway, KLABJON L, 1+1, два сэндвича с бантом, кнопка «Заказать в приложении», maxway.delever.uz |

## Музыка

`music.py` синтезирует трек на numpy без сэмплов: 120 BPM, фа мажор, хаус-грув (бочка, клэп, хэты),
офбит-бас с сайдчейном, синт-стэбы, щипковая мелодия-хук, райзеры и удары. Звуки интерфейса привязаны к кадру:
попы наклеек, тапы, монета на бейдже, счётчик и «ка-чинг» на 0 сум, «боинг» банта, скрип маркера.
Громкость нормализуется до −14 LUFS.

## Сборка

Нужны Node.js с Playwright (Chromium), Python 3 с numpy и Pillow, ffmpeg.

```bash
./build.sh                                  # музыка → кадры → out/maxway-klabjon-1080x1920.mp4
node render.mjs --stills 4.5,12.3,20.8      # стоп-кадры для проверки в out/stills/
```

Предпросмотр в браузере: `index.html` (по кругу) или `index.html?t=15.9` (стоп-кадр).
Всё движение — в `motion.js`, функция `renderAt(t)` детерминированно рисует кадр для момента `t`.

Ассеты в `assets/` вырезаны из присланных скриншотов приложения и баннера (сэндвич, ключевой визуал с бантом,
логотип, баннер с главной, фото товаров). Шрифты Unbounded и Rubik — Google Fonts, SIL Open Font License.
