MAXWAY — KLABJON 1+1 · проект для After Effects 2025
1080×1920 (9:16), 60 fps, 30 секунд, с музыкой

КАК ОТКРЫТЬ
1. Установите шрифты из папки fonts (все 8 файлов .ttf: Unbounded и Rubik).
   Windows: выделить → правый клик → «Установить для всех пользователей».
   macOS: двойной клик → «Установить шрифт».
   После установки перезапустите After Effects.
2. After Effects 2025 → File → New → New Project.
3. File → Scripts → Run Script File… → build_maxway_klabjon.jsx
   Папку не разбирайте: скрипт берёт файлы из footage/ и audio/ рядом с собой.
4. Дождитесь сообщения «Готово» (обычно 1–3 минуты) и сохраните проект: File → Save As.

ЧТО ВНУТРИ ПРОЕКТА
MAXWAY KLABJON 1+1 · 1080×1920 — главная композиция:
  • 9 сцен-прекомпов (01 Хук … 09 Финал), привязаны к нулю «CAM · удары и тряска»;
  • прекомп «Телефон · приложение Maxway» (3D-слой) и «Камера · перспектива телефона»;
  • прекомпы «Карта доставки» и бегущих лент;
  • наклейки, конфетти, шторки-переходы, HUD по углам, вспышка, зерно (Noise), виньетка;
  • музыка «Музыка · 120 BPM».
Тексты — родные текстовые слои AE (их можно править), картинки интерфейса и наклейки — PNG.
Цветные слова внутри текста (например, жёлтое KLABJON) сделаны текстовым аниматором «Цвет».

Позиция у слоёв разделена по осям (X Position / Y Position).
Движение записано из исходного ролика по кадрам и прорежено до опорных ключей,
поэтому совпадает с готовым видео. Чтобы сдвинуть анимацию по времени — выделите ключи и перетащите.
