# WOBBLE BRAWL — физические драки желейных человечков (Unity 6)

Локальная мультиплеерная игра в духе **Gang Beasts** и **Human: Fall Flat**: желейные
человечки на активных рэгдоллах дерутся, хватают друг друга, лазают, таскают ящики и
выбрасывают соперников с арены. Плюс кооперативный уровень-головоломка «Восхождение».

Весь контент (персонажи, арены, эффекты, звук, музыка, интерфейс) **генерируется кодом**,
поэтому в проекте нет ни одного бинарного ассета. Открыл проект, нажал Play, играешь.

---

## Быстрый старт

1. Установи **Unity 6** (проект создан под `6000.0.85f1` LTS, подойдёт любой 6000.x).
2. В Unity Hub: **Add → Add project from disk** → выбери папку `WobbleBrawl`.
3. При первом открытии Unity скачает пакеты (Input System, uGUI). Если появится окно
   *«Enable the new input system backends?»*, нажми **Yes**: редактор перезапустится,
   и заработают геймпады. (Если нажать No, игра тоже работает, но только с клавиатурой и мышью.)
4. Скрипт `WobbleProjectSetup` сам создаст сцену `Assets/WobbleBrawl/Scenes/Main.unity`,
   добавит её в Build Settings и откроет её.
5. Нажми **Play** (или меню **Wobble Brawl ▸ Play**).

> Игра стартует из **любой** сцены: `Bootstrap` через `RuntimeInitializeOnLoadMethod`
> поднимает `GameManager`, и тот строит мир. Чтобы отключить автозапуск в своей сцене,
> добавь в неё компонент `NoAutoBoot`.

Сборка: **File ▸ Build Profiles** → Windows/Mac/Linux → Build. Работает и в Built-in RP,
и в URP: материалы берутся из стандартного материала текущего пайплайна.

## Управление

| Действие | Клавиатура + мышь | 2-й игрок (клавиатура) | Геймпад |
|---|---|---|---|
| Войти в лобби | ПРОБЕЛ | ПРАВЫЙ SHIFT / Num0 | A / START |
| Ходьба | WASD | Стрелки | Левый стик / крестовина |
| Прыжок | ПРОБЕЛ | ПРАВЫЙ SHIFT / Num0 | A |
| Левая / правая рука (держать = схватить) | ЛКМ / ПКМ | `,` `.` / Num1 Num2 | LT / RT (или LB / RB) |
| Высота рук | Мышь вверх/вниз, колесо | L / K, Num8 / Num5 | Правый стик (Y — вверх) |
| Удар | F (или средняя кнопка мыши) | `/` / Num3 | X |
| Пинок (в прыжке — дропкик) | E | `;` / Num. | B |
| Пауза | ESC | — | START |
| В лобби: шляпа / цвет | F / Q | `/` / P | X / Y |
| Выйти из слота | BACKSPACE | DELETE | SELECT |

**Приёмы**
- **Нокаут.** Удары по голове опустошают шкалу сознания. Вырубленный обмякает на несколько секунд.
- **Бросок.** Схвати вырубленного обеими руками (руки вниз), подними руки вверх и отпусти обе кнопки.
- **Удар головой.** Держишь врага двумя руками и бьёшь: вместо кулака получается удар головой.
- **Вырваться.** Тебя схватили: жми прыжок или удар. Вырубили: жми прыжок, чтобы очнуться быстрее.
- **Лазанье.** Подними руки, схватись обеими за край и держи прыжок: персонаж подтянется. Потом толкай стик вперёд.
- **Дропкик.** Прыжок, потом пинок. Мощно, но сам ты после него падаешь.

## Режимы

| Режим | Правила |
|---|---|
| **ДРАКА** | Все против всех, побеждает последний оставшийся на арене. Матч идёт до N побед. Через 2 минуты включается «внезапная смерть» с двойным уроном. Победитель раунда носит корону. |
| **ЦАРЬ ГОРЫ** | Стой в светящейся зоне один, чтобы набирать очки. Зона переезжает каждые 22 с. Упавшие возрождаются. Матч идёт до 30 очков. |
| **ВОСХОЖДЕНИЕ (кооп)** | Головоломка-платформер в стиле Human: Fall Flat на 1–4 игроков: уступы, ящики, кнопка-противовес, движущаяся платформа, крутящееся бревно или турник, батут к вершине. У каждого участка есть общий чекпоинт и подсказка. |

Боты (от 0 до 6, сложность настраивается) добавляются в «Драку» и «Царя горы», так что
играть можно и одному. На титульном экране боты всё время дерутся на фоне.

## Арены

| Арена | Особенность |
|---|---|
| **Крыша** | Небоскрёб на закате, по крыше ходит шар-баба на кране. Можно залезть на водонапорную башню и билборд. |
| **Фабрика** | Конвейеры тащат к дробилкам, поршни из стены выталкивают с переднего края, есть узкие мостки. |
| **Колесо обозрения** | Работающее колесо: можно запрыгнуть в кабинку и драться наверху, а внизу ждёт море. |
| **Льдины** | Скользкие плавучие льдины под снегопадом. Если столпиться на краю, льдина накренится. |
| **Башня** | Кооперативный уровень «Восхождение» над облаками. |

## Что изучено и что взято из оригиналов

**Gang Beasts** (Boneloaf): персонажи держатся на ногах силой «мышц» (моторов суставов),
а не анимацией. Главный цикл: подраться → вырубить → поднять → выбросить с арены.
Арены с опасностями (грузовики, мясорубки, колёса обозрения), общий камера-план,
локальный мультиплеер с мгновенным входом.

**Human: Fall Flat** (No Brakes Games): каждая рука управляется отдельно, высота рук
задаётся камерой или стиком, рука прилипает к тому, чего коснулась. Лазанье устроено
как «схватиться и подтянуться», а у головоломок несколько решений (ящик, напарник, обход).

**Что сделано лучше / иначе:**
- Оба жанра в одной игре: PvP-арены и кооп-головоломка на одном и том же физическом персонаже.
- Боты с настоящей «гэнг-бистовской» тактикой: они вырубают, хватают, тащат к краю и
  выбрасывают. Одному играть не скучно.
- Мягкая помощь игроку: автонаведение удара, подсказки на чекпоинтах, частичная
  компенсация веса при переноске и висе на руках, мэш-кнопка, чтобы очнуться и вырваться.
- Сочность: хит-стоп при нокауте, тряска камеры, вибрация геймпада, искры, пыль, брызги,
  конфетти, гуглы-глаза, X-глаза и звёздочки при нокауте, мимика.
- Всё процедурное: игру легко моддить, а новая арена — это один класс.

### Как устроен активный рэгдолл

1. **Тело.** Таз, грудь, голова, плечи, предплечья (с кулаком), бёдра и голени (со стопой):
   всего 11 `Rigidbody`. Тело собирается в позе покоя с нулевыми относительными поворотами,
   поэтому целевой поворот мышцы — это просто `Inverse(желаемый локальный поворот)`.
   Пределы суставов заданы в той же системе знаков, что и в Ragdoll Wizard Unity.
2. **Баланс.** PD-момент на таз и грудь держит их вертикально и разворачивает по направлению взгляда.
   «Ховер» (сфер-каст из таза вниз и пружина к высоте стояния) несёт вес тела, а ноги
   анимируются процедурно. Так Gang Beasts-подобные игры получают устойчивую, но шаткую ходьбу.
   Реакция ховера давит на динамическую опору: льдины кренятся, ящики проседают.
3. **Ходьба.** Ускорение отслеживает целевую скорость относительно поверхности
   (`ISurfaceVelocity`: конвейеры, кабинки, движущиеся платформы).
4. **Руки.** Целевое направление руки берётся из взгляда и угла рук, к нему добавляется
   PD-тяга кулака к точке. Захват: `FixedJoint` к ближайшему коллайдеру под кулаком,
   к миру при лазанье. У захвата есть прочность на разрыв.
5. **Сознание.** Урон зависит от скорости удара и части тела. На нуле наступает нокаут:
   сила мышц падает до 5%, руки разжимаются. После пробуждения сила плавно возвращается, и персонаж «встаёт».

### Как добавить арену

```csharp
public sealed class MyArena : Arena
{
    public override string Title => "Моя арена";
    public override string Subtitle => "Описание";
    protected override void BuildGeometry()
    {
        KillY = -5f;
        Kit.Box(Root, new Vector3(0, -0.5f, 0), new Vector3(12, 1, 12), Color.gray);
        Kit.Crate(Root, new Vector3(2, 0.5f, 0), Vector3.one, new Color(0.7f, 0.5f, 0.3f), 12f);
        SpawnRing(Vector3.zero, 3f, 8, 0.05f);
        HillSpots.Add(Vector3.zero);
    }
}
```
Затем добавь её в `ArenaCatalog` (`Arena.cs`).

### Настройка ощущений

Все параметры лежат в `Core/Tune.cs`: сила мышц, пружина баланса, скорость, прыжок,
урон, длительность нокаута, сила броска, помощь при лазанье. Самые «вкусные»:
`HoverSpring`, `UprightSpring`, `Shoulder`, `PunchSpeed`, `ThrowForward`, `KnockoutBase`.

## Технологии

- **Unity 6** (6000.0 LTS), PhysX: `ConfigurableJoint` со Slerp-приводом, `FixedJoint`,
  непрерывные столкновения, 90 Гц физики, 14 итераций солвера.
- **Input System 1.14** (локальный мультиплеер, горячее подключение геймпадов, вибрация).
  Есть запасной путь через старый Input Manager.
- **uGUI 2.0**, интерфейс целиком из кода.
- Built-in RP и URP без изменений кода.
- Процедурный звук (`AudioClip.Create`): удары, вздохи-«хыть», колокол нокаута, толпа, музыка.
